# 訪問の情報

訪問の情報は、訪問の予定に付き、誰を、誰が、どのサービスで訪問するかを持つ。

## States and Transitions

訪問の情報は、訪問の予定を作るときに作る。  
予定を変えると、訪問の情報を作り直す。  
前の訪問の情報は、どの予定と、Google カレンダーに書いた予定の記録も指さなくなったときに消す。

## Invariants

- 利用者、主訪問者、同行者は、予定と同じ事業所に属する。
  - 違うときの応答は、[事業所の分離](facility.md) の Invariants にある。
- 同行者は、主訪問者と同じ職員にできない。
- 訪問の区分（夜勤、緊急、入院）は複数を付けられ、同じ区分を重ねない。
- サービスコードは、事業所に属さないマスタから選ぶ。
  - マスタの扱いは、[事業所の分離](facility.md) の Invariants にある。
- `google_primary` の事業所で buddy から作った予定の訪問の情報は、buddy の予定の ID を主キーにする記録（`calendar_event_records`）が指す。
  - 記録は、結び付けたカレンダーと Google の予定の ID の組で 1 つに決まる。
  - 記録が指すのは、Google が受けたと分かった版の訪問の情報と、書き込みの保留の版の訪問の情報の 2 つまでである。
  - 保留の版を確定すると、保留の版の訪問の情報が確定した訪問の情報になり、前の訪問の情報はどの予定と記録も指さなければ消す。
  - Google が書き込みを拒んだことが確かなときは、保留の版の訪問の情報を消す。作成を拒んだときは、記録も消す。
- Google で作った予定に訪問の情報を足して保存すると、記録ができ、その予定の一覧での ID を主キーにする。
- 主訪問者を替えて予定を別のカレンダーに移すと、記録のカレンダーと Google の予定の ID が替わり、主キーは変わらない。
- 予定をキャンセルすると、記録と訪問の情報を消す。
  - Google が書き込みを受けたかが分からない間は、保留の版の訪問の情報を消さない。
  - ADR-0026: [Google カレンダーとの連携を、事業所ごとの正本のモードで分ける](../../docs/adr/0026-google-calendar-sync.md)

## Prohibitions

- 通常の予定に訪問の情報を付けない。
