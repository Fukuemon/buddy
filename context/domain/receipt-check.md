# 照合

照合は、ある月の予定と実績を対にし、4 つの区分に分ける。対の作り方、判定の規則、画面の表示、元の実装との違いは [レセプトの照合の Design Doc](../../apps/receipt-api/DesignDoc.md) にある。

## States and Transitions

| 区分 | 意味 |
| --- | --- |
| 予定のみ | 対になる実績が無い |
| 実績のみ | 対になる予定が無い |
| 整合 | 予定と実績が対になり、時間、サービス、加算が規則に合う |
| 不整合 | 予定と実績が対になったが、規則に合わない項目がある |

- 予定は、予定の CSV か、Google カレンダーの対象の月から取る。

## Invariants

- 対のキー（訪問日、利用者名、主訪問者）が同じものだけを対にする。
- API は判定の結果の JSON だけを返す。印と CSV の書き出しは画面が作る。

## Prohibitions

- 入力の CSV と照合の結果を保存しない。
- Google カレンダーの予定のうち照合に使わなかったものを返すときに、題名を返さない（利用者名を含むため）。
