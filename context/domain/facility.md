# 事業所の分離

事業所は、データを分ける単位である。  
職員は、自分の事業所のデータだけを扱う。

## States and Transitions

事業所は、ID ブローカーの組織と `facilities.org_id` で結び付く。  
結び付くまで、その事業所の職員はログインできない。

## Invariants

- トークンの組織の事業所、職員の事業所、パスが指すリソースの事業所の 3 つが一致する。
  - 一致しなければ 403 になる。
- 本文が指す参照（職員、部署、チーム、役職、利用者）は、同じ事業所のものに限る。
  - 違えば 400 になる。
- 部署、チーム、役職の名前は、事業所の中で一意である。
- 予定の種類、サービスコード、訪問の区分、9 つの権限は、事業所に属さないマスタである。
  - マスタはマイグレーションが入れ、API では作らない。

## Prohibitions

- 一覧と作成は、事業所の ID で絞る。
- 事業所を確認せずに 1 件を返さない。
  - ID で 1 件を指すリクエストは、取った後にリソースの事業所を職員の事業所と比べ、違えば 403 にする。
- 照合の API は事業所のデータを持たず、保存しない。
