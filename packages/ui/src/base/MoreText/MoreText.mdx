# MoreText

「詳しく」で開く補足。常に出す 1 文の下に「詳しく」のボタンを置き、押すと続きの説明を開く。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `MoreText` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`HelpToggle`、`MoreText`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `FOCUS-ONE`
  - `TARGET-SIZE`
