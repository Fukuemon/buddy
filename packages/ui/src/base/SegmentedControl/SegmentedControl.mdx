# SegmentedControl

2 から 4 個の選択肢から 1 つを選び、すぐに表示を切り替える。ラジオボタンの組として振る舞う。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `SegmentedControl` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`SegmentedControl`、`Select`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `FOCUS-ONE`
  - `TARGET-SIZE`
