# Drawer

画面の左端から重ねて出すモーダルのサイドバー。`<dialog>` の `showModal()` で開き、後ろの画面を操作できなくする。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `Drawer` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`Drawer`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `TARGET-SIZE`
  - `FOCUS-ONE`
