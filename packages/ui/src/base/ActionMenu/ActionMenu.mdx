# ActionMenu

「…」のボタンと、押すとボタンの下に開く操作のメニュー。

## 使う場面

- 一覧の行に、2 つ以上の操作（取り込む、外す）を置く

## 使わない場面

- 操作が 1 つだけ（`Button` を行に置く）
- 選んだ値を保つ選択（`SegmentedControl` か選択肢のカード）
- ナビゲーション

## Do

- `label` には、何の操作かが分かる名前（「青木 一郎の操作」）を渡す
- データを失う操作には `isDanger` を付ける。赤くし、線で分けて最後に置く
- 今は選べない項目は `disabled` にし、理由を画面の近くに出す
- データを失う操作は、選んだ後に `ConfirmDialog` で確認する
- ダイアログを開かずにその場で送る操作には `staysOpenUntilSettled` を付け、`onSelect` から送る処理の Promise を返す。送っている間は、項目の文言を送っていることを示す文言にし、`disabled` にする

## Don't

- メニューの項目から、確認を挟まずにデータを失う操作を実行する
- 項目を 6 個以上並べる

### 文言のボタンで上に開く

`triggerLabel` を渡すと、「…」の代わりに文言のボタンを出す。モーダルの下端のように下に場所が無いところでは、`placement="top"` で上に開く。押せない項目の理由は `description` に書く。

<Canvas of={Stories.TextTriggerOpensUp} />

## キーボードの操作

- Tab で「…」のボタンに移り、Enter と Space で開く
- 開くと最初の項目にフォーカスが移る。Tab で次の項目に移る
- Enter と Space で項目を選ぶと、メニューを閉じる。`staysOpenUntilSettled` の項目は、送った結果が返ってから閉じ、フォーカスを「…」のボタンに戻す
- Esc で閉じ、フォーカスを「…」のボタンに戻す
- メニューの外を押すと閉じる
