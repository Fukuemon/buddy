# Button

操作を 1 つ実行するボタン。`variant` で主、副、削除、確定の削除を、`size` で S、M、L を選ぶ。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `Button` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`Button`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `PRIMARY-ACTION-ONE`
  - `TARGET-SIZE`
  - `FOCUS-ONE`

## 状態

hover は文字に下線が付き、フォーカスは `focus-ring` を出す。story の上で操作して確認する。
