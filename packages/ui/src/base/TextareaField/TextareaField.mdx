# TextareaField

見出しつきの複数行の入力。React Hook Form の `control` と `name` を受ける。

## 使う場面

- メモのような複数行の文を入力する

## 使わない場面

- 1 行で足りる名前やタイトル

## Do

- `label` に項目の名前を渡す

## Don't

- 見出しを空にする

## キーボードの操作

- Tab で欄に移る
- Enter で改行する
- エラーがあると `aria-invalid` を付け、`aria-describedby` でエラーの文を指す
