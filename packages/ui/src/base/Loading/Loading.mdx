# Loading

画面全体かダイアログの中身を待つ間に出す、回転するインジケーター。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `Loading` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`Loading`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `MOTION-TOKEN`
  - `MOTION-REDUCE`
