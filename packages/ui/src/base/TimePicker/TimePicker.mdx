# TimePicker

時刻を 1 つ入力する欄。ブラウザの `input type="time"` を使い、値は `HH:mm` の文字列。React Hook Form の `control` と `name` を受ける。

## 使う場面

- 予定の開始と終了の時刻を入力する

## 使わない場面

- 時間の長さ（`NumberPicker` を使う）

## Do

- `label` に項目の名前を渡す

## Don't

- ラベルを空にする

## キーボードの操作

- Tab で欄に移る
- ブラウザの時刻の入力欄の操作に従う
- エラーがあると `aria-invalid` を付け、`aria-describedby` でエラーの文を指す
