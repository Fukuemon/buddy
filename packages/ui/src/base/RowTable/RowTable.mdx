# RowTable

1 行が 1 つの対象を表す一覧の表。幅 768px 以上では表にし、幅 768px 未満では、1 行目に名前、2 行目に補足の値を並べる 2 行のリストにする。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `RowTable` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`Table`、`RowTable`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `STATE-NOT-COLOR-ONLY`
  - `LAYOUT-OVERFLOW`
  - `FOCUS-ONE`
  - `TARGET-SIZE`

## 状態

hover は行に面の色を付け、フォーカスは行の全体に `focus-ring` を出す。story の上で操作して確認する。
