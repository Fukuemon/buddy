# Dialog

画面の上に重ねて出す、小さい確認と入力のダイアログ。`<dialog>` の `showModal()` で開き、後ろの画面を操作できなくする。中身は `DialogHeader`、`DialogBody`、`DialogFooter` で組む。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `Dialog` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`Modal`、`Dialog`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `PRIMARY-ACTION-ONE`
  - `FOCUS-ONE`
