# FileField

ファイルを 1 つ選ぶ欄。ブラウザの `input type="file"` を使い、選んだファイルを `onFileChange` に渡す。見出し、補足の文、誤りの文は `FormField` で並べる。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `FileField` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`FileField`」
- 欄の枠と面の状態: コンポーネントの文書の「入力の欄の状態」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `STATE-NOT-COLOR-ONLY`
  - `FOCUS-ONE`
  - `TARGET-SIZE`
