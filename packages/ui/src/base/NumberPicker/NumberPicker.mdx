# NumberPicker

単位の決まった数を入力する欄。値は number。React Hook Form の `control` と `name` を受ける。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `NumberPicker` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`FormField`、`NumberPicker`、`TextareaField`」
- 欄の枠と面の状態: コンポーネントの文書の「入力の欄の状態」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `SPACING-SCALE`
  - `STATE-NOT-COLOR-ONLY`
  - `FOCUS-ONE`
