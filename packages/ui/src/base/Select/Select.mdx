# Select

決まった選択肢から 1 つを選ぶ欄。ブラウザの `select` を使い、標準の矢印を消して、欄の右から 12px の位置に矢印の印を置く。
右の余白を矢印の分だけ広げ、長い選択肢の文字が矢印に重ならないようにする。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `Select` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`SegmentedControl`、`Select`」
- 欄の枠と面の状態: コンポーネントの文書の「入力の欄の状態」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `FOCUS-ONE`
  - `TARGET-SIZE`
