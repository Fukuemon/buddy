# SearchBox

一覧を語で絞り込む検索欄。入力のたびに `onSearch` を呼ぶ。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の `SearchBox` の行
- 使い方の規則と Do と Don't: コンポーネントの文書の「コンポーネントごとの規則」の「`SearchBox`」
- 枠と面の状態（hover、フォーカス、無効）: コンポーネントの文書の「入力の欄の状態」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `FOCUS-ONE`
