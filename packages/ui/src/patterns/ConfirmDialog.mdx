# ConfirmDialog

取り消せない操作の確認のダイアログ。`role="alertdialog"` の幅の狭い `Dialog` に、問いの形のタイトル、説明、「キャンセル」と確定のボタンを組んだ形。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、使い方の規則、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「パターン」の「`ConfirmDialog`」
- 中で使うコンポーネントの規則: コンポーネントの文書の「コンポーネントごとの規則」の「`Modal`、`Dialog`」と「`Button`」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `PRIMARY-ACTION-ONE`
