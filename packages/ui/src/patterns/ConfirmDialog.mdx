# ConfirmDialog

取り消せない操作の確認のダイアログ。`role="alertdialog"` の幅の狭い `Dialog` に、問いの形のタイトル、説明、「キャンセル」と確定のボタンを組んだ形。

## 使う場面

- カレンダーを外す、予定を書き直すのような、データを失う操作を実行する前に確認する

## 使わない場面

- 取り消せる操作。確認を挟まずに実行する
- 入力を受ける（`InputDialog` を使う）
- 完了の通知

## Do

- タイトルは問いの形にする（「カレンダーを外しますか」）
- 説明には、何が失われ、何が残るかを書く
- データを失う操作の確定は `submitVariant="danger"` にし、文字を操作の動詞（「外す」）にする
- 送っている間は `isSubmitting` を渡す。どの操作でも閉じなくなる
- 確定が何かを取り消すかやめる操作の確認（「予定をキャンセルする」「やめる」「書き直す」）では、`cancelLabel` に「戻る」を渡す

## Don't

- × を置く。フッターの「キャンセル」で閉じる
- 確定のボタンの文字を「はい」「OK」にする
- 閉じる側の「キャンセル」と、「キャンセル」の語を持つ確定のボタンを並べる。どちらが予定を取り消すのかを読み違える

## キーボードの操作

- 開くと「キャンセル」にフォーカスが移る
- Tab と Shift+Tab はダイアログの中の要素に移る
- Esc で `onCancel` を呼ぶ。送っている間は呼ばない
- 閉じると、開く前にフォーカスがあった要素へ戻る
