# アクセシビリティの基準

DADS が参照する WCAG 2.2 の AA を基準にする。
基準ごとに、自動で確認する仕組みを packages/ui に置いている。

- 出典: [DADS のアクセシビリティ](https://design.digital.go.jp/dads/guidance/accessibility/)

## 文字のコントラスト

文字と背景の組は 4.5:1 以上にする。面の上の状態の色の文字も含む。
全ての story で a11y のアドオン（axe）を動かし、違反を `pnpm --filter @buddy/ui test` の失敗にする。
意味のトークンの組は、ルートの `pnpm check:contrast`（`scripts/check-contrast.mjs`）でも計算する。

## 文字でないもののコントラスト

入力欄と押せるものの枠（`border-field`）と、フォーカスの表示は 3:1 以上にする。
axe は枠の色を確認しないので、意味のトークンの組のコントラストを `pnpm check:contrast` で計算する。

## フォーカスの見え方

全ての操作できる要素で、`:focus-visible` に `focus-ring` を出す。
DADS の指針の、要素に接する黄色の輪と、その外の黒の枠の 2 重の表示である。

## ターゲットの大きさ

ボタンと入力欄は 44×44 CSS px 以上を押せるようにする。
S のボタンのように見た目が小さいものは、見た目の外に押せる領域を広げる。
コンポーネントの Vitest のテストが、ブラウザで描画した大きさを確認する。

## キーボードの操作

コンポーネントごとの操作を、各コンポーネントのページの「キーボードの操作」に書く。
コンポーネントの Vitest のテストが、ブラウザのキーの操作で、その通りに動くことを確認する。
