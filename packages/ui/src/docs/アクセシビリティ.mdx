# アクセシビリティの基準

基準と確認の方法の本文は、DESIGN.md の「アクセシビリティ」にある。
基準は、次の項目ごとに決めている。

- 文字のコントラスト
- 文字でないもののコントラスト
- フォーカスの見え方
- ターゲットの大きさ
- キーボードの操作
- 入力の誤りの伝え方
- 動きを減らす設定

コンポーネントごとのキーボードの操作は、コンポーネントの文書（`packages/ui/design/components.md`）の「コンポーネントの選び方」の表にある。
