# 色

画面とコンポーネントは、意味のトークンだけを使う。
ユーティリティの名前は、Tailwind の `bg-`、`text-`、`border-`、`ring-` の後ろに、意味のトークンの名前を付けたもの（`bg-primary`、`text-text-secondary`）。
値は DADS の `@digital-go-jp/design-tokens` の変数を参照し、参照の対応は `src/tokens/semantic.css` にある。

- 出典: [DADS の色](https://design.digital.go.jp/dads/foundations/color/)

## 文字

文字の色は、`surface` の上で 4.5:1 以上になる。`text-disabled` だけは、WCAG の文字のコントラストの対象外の、無効のコンポーネントに限って使う。

## 状態

状態の色は、文字の色と、同じ系統の薄い面の組で使う。`*-surface` の面の上の文字は、同じ系統の文字の色か `text` にする。
状態を色だけで伝えず、文と印を一緒に出す。

## フォーカス

フォーカスの表示は `focus-ring` のユーティリティだけを使う。黄色の輪（`--buddy-color-focus-halo`）と、その外の黒の枠（`--buddy-color-focus-outline`）の 2 重の表示である。
