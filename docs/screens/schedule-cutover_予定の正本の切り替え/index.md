# schedule-cutover 予定の正本の切り替え

Google カレンダーで予定を管理している事業所で、予定を buddy に取り込み、事業所の予定の正本を buddy に切り替える画面。  
マネージャーが、切り替えを始め、職員ごとの取り込みの状況を見て、完了するかやめる。

| 項目 | 値 |
| --- | --- |
| URL | `/schedule/link/cutover` |
| 使う人 | 職員の管理の権限を持つ職員（デフォルトはマネージャー） |
| 実装 | `apps/web/src/routes/schedule_.link_.cutover.tsx`、`apps/web/src/features/calendar/components/CalendarCutoverContainer.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

**活性条件**: 常に活性

**表示条件**: 「やめる前の確認」の状態のほかの全ての状態で表示

## 切り替えの手順

**概要**: 切り替えの 3 つの段階を、番号付きで示す

**値のソース**: 次の文言。

| 箇所 | 文言 |
| --- | --- |
| 文言 | 「切り替えを始めます。始めた月の初日から先の全ての予定が、取り込みの対象になります。」「職員ごとに、予定を取り込みます。取り込みの間も、予定のカレンダーには Google カレンダーの予定が出ます。」「全ての職員を取り込み、同期が終わったら、完了します。」 |

**活性条件**: 常に活性

**表示条件**: 「切り替えの前」と「始められない」の状態で表示

## Google カレンダーを変えない案内

**概要**: 切り替えの間に、職員に Google カレンダーで予定を変えないよう頼むことを、マネージャーに伝える

**値のソース**: 次の文言。

| 箇所 | 文言 |
| --- | --- |
| 文言 | 見出しは「切り替えの間は、Google カレンダーで予定を変えない」。本文は「職員に、切り替えが終わるまで Google カレンダーで予定を作成、変更しないよう頼んでください。取り込んだ後に変えた予定は、完了するときに見つかり、取り込み直すまで完了できません。」 |

**活性条件**: 常に活性

**表示条件**: 「切り替えの前」「始められない」「切り替え中」「完了できない」の状態で表示

## カレンダーの一覧

**概要**: Google カレンダーを結び付けた職員ごとの、最後の同期の時刻と、この切り替えの最後の取り込みの時刻

**値のソース**: 職員の名前。  
最後の同期は、最後に同期できた時刻（「2026/11/05 08:59」の形）で、同期していなければ「まだ同期していない」、最後の同期が失敗していれば時刻の後に「（最後の同期は失敗）」を付ける。  
切り替え中は、この切り替えの最後の取り込みの時刻を出し、取り込んでいなければ「まだ取り込んでいない」と出す

**活性条件**: 常に活性

**表示条件**: 「切り替えの前」「始められない」の状態では、職員と最後の同期の 2 つのカラムで表示。  
「切り替え中」「完了できない」の状態では、この切り替えの最後の取り込みのカラムと、取り込むのリンクを足して表示

**概要**: 切り替えを始めるボタン。  
画面の主ボタン

**値のソース**: 次の文言。

| 箇所 | 文言 |
| --- | --- |
| 文言 | 「切り替えを始める」。押した後、終わるまでは「始めています」 |

**活性条件**: 始めている間のほかは活性

**表示条件**: 「切り替えの前」と「始められない」の状態で表示

## 完了できない一覧

**概要**: 完了の条件を満たさない職員と予定を、日時と理由と次にすることで並べる

**値のソース**: 次の文言。

| 箇所 | 文言 |
| --- | --- |
| 文言 | 見出しは「完了できません（2 件）」。説明は「次のカレンダーと予定が、完了の条件を満たしていません。直してから、もう一度完了してください。」。行ごとに職員の名前、日時（「2026/11/10（火）10:00〜10:30」の形。職員ごとの理由と、Google で消えた予定は空にする）、理由、次にすることを出す。理由と次にすることの組は次のとおり。 |

| 理由 | すること |
| --- | --- |
| 「この切り替えで、まだ取り込んでいない」 | 「取り込んでください」 |
| 「最後の取り込みの後に、同期が成功していない」 | 「同期が終わるまで待ってから、もう一度完了してください」 |
| 「取り込んでいない予定がある」 | 「取り込み直してください」 |
| 「確認が必要な予定の取り込み方を決めていない」 | 「取り込み直して、取り込み方を選んでください」 |
| 「取り込んだ後に Google で変わった」 | 「取り込み直すと、Google の内容で上書きします」 |
| 「取り込んだ後に Google で消えた」 | 「取り込み直すと、buddy の写しを消します」 |

**活性条件**: 常に活性

**表示条件**: 「完了できない」の状態で表示。  
予定のタイトルは利用者名を含むので出さない

## 完了する

**概要**: Google カレンダーを読み直して完了の条件を確認し、満たせば事業所の予定の正本を buddy にするボタン。  
画面の主ボタン

**値のソース**: 次の文言。

| 箇所 | 文言 |
| --- | --- |
| 文言 | 「完了する」。押した後、終わるまでは「確認しています」 |

**活性条件**: 確認している間のほかは活性

**表示条件**: 「切り替え中」と「完了できない」の状態で表示

### インタラクション

3. Google カレンダーを読めないときは、ボタンの上に完了の失敗の文を出す。

## 全体動作

### 使う場面

事業所が Google カレンダーでの予定の管理に慣れ、buddy で予定を管理すると決めたときに、マネージャーが 1 度だけ使う。  
切り替えの間は、職員に Google カレンダーで予定を変えないよう頼み、職員ごとに取り込んでから完了する。  
手順と確認の条件は [ADR-0028](https://github.com/Fukuemon/buddy/blob/develop/docs/adr/0028-calendar-cutover.md) にある。

### 初期処理

開くと「読み込み中」の状態にし、事業所の予定の正本と切り替えの状況を読む。  
読み終えたら、切り替え中なら「切り替え中」、事業所が buddy で予定を管理していれば「正本が buddy」、ほかは「切り替えの前」の状態にする。  
URL の search params は読まない。

### 変えた後の表示

- 始めると、予定のカレンダーの上に、切り替え中であることと、Google カレンダーで予定を変えないよう頼む文が出る。
- 切り替えの間も、予定のカレンダーと照合は Google カレンダーの予定を出す。取り込んだ予定は、完了するまで出ない。
- 完了すると、予定のカレンダーで予定を作れるようになり、Google カレンダーの予定の同期をやめる。
- やめると、切り替え中の表示が消え、事業所の予定は Google カレンダーで管理したままになる。

### 権限の確認

職員の管理の権限が無い職員には、画面を出さずに、権限が無いことを出す。形は目次の [全ての画面に共通する状態](../index.md#全ての画面に共通する状態) にある。
