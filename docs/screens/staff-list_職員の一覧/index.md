# staff-list 職員の一覧

職員の管理の権限を持つ職員が、事業所の職員を、部署、チーム、役職、在籍の状態とともに一覧し、登録と詳細へ移る画面。  
退職の職員は、状態の絞り込みで出す。

| 項目 | 値 |
| --- | --- |
| URL | `/staff` |
| 使う人 | 職員の管理の権限を持つ職員（デフォルトはマネージャー） |
| 実装 | `apps/web/src/routes/staff.tsx`、`apps/web/src/features/staff/components/StaffListContainer.tsx`、`apps/web/src/features/staff/components/StaffListView.tsx`、`apps/web/src/components/site/RowTable.tsx`、`apps/web/src/components/site/ListTools.tsx`、`apps/web/src/components/site/PageForbiddenMessage.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

## 構成

ヘッダーの左に、メニューのボタンと buddy を置く。  
ヘッダーの右には、アカウントのボタンを置く。  
ヘッダーの下の左端には、画面の間を移るナビゲーションを置く。  
ナビゲーションは、見出し「予定」の下にカレンダー、取り込み、要確認、連携を並べ、見出し「照合」の下に照合を、見出し「職員」の下に職員を並べる。  
取り込み、要確認、連携と、見出し「職員」のまとまりは、職員の管理の権限を持つ職員にだけ出す。  
今の画面の職員に印を付ける。  
幅 768px 以上では、ナビゲーションを幅 224px の開いた形で始め、メニューのボタンで幅 80px のレールと切り替える。  
幅 768px 未満では、ナビゲーションをドロワーにし、閉じた状態で始める。  
ナビゲーションの印は、幅 768px 未満ではドロワーを開くと出る。

ヘッダーの下の、ナビゲーションの右に、ページのタイトルとヘルプと職員を登録のボタン、名前の検索と絞り込みと人数、職員の一覧を縦に並べる。  
職員の一覧は、[画面仕様書の規約の一覧](../rules.md#一覧) の形にする。  
幅 768px 以上では、行全体を押せる表にする。  
幅 768px 未満では、1 行目に名前と状態の印、2 行目に部署、チーム、役職を「・」でつなげた 2 行のリストにし、頭文字の丸とメールアドレスを出さない。  
ヘルプの説明の印は、ヘルプを開くと出る。

## メニュー

**概要**: ナビゲーションの形を切り替える。  
幅 768px 未満では、ナビゲーションのドロワーを開く。

**値のソース**: 3 本の横線のアイコン。  
読み上げる名前は「メニュー」。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの左端に出す。

**カタログ**: [SiteLayoutContainer の Mobile](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitelayoutcontainer--mobile)

### インタラクション

#### 1. 幅 768px 以上で押す

1. ナビゲーションを、開いた形からレールに切り替える。もう一度押すと開いた形に戻る。

#### 2. 幅 768px 未満で押す

1. 左端からナビゲーションのドロワーが開く。

## ナビゲーション

**概要**: 予定、照合、職員の画面の間を移る。

**値のソース**: 見出し「予定」の下に、「カレンダー」「取り込み」「要確認」「連携」のアイコンと名前を並べる。  
見出し「照合」の下に、「照合」のアイコンと名前を置く。  
見出し「職員」の下に、人のアイコンと「職員」を置く。  
確認が必要な予定の件数を、「要確認」の右端に印で示す。  
今の画面に面の色の印を付ける。  
この画面では「職員」に付ける。  
レールでは見出しを出さず、アイコンの下に名前を置き、見出しのまとまりの間を区切り線で分ける。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの下の左端に出す。  
幅 768px 以上では、この画面では開いた形で始める。  
幅 768px 未満では、メニューのボタンで開いたドロワーの中に出す。  
「取り込み」「要確認」「連携」と、見出し「職員」のまとまりは、職員の管理の権限を持つ職員にだけ出す。

**カタログ**: [SiteNav の Manager](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitenav--manager)

### インタラクション

#### 1. 「カレンダー」を押す

1. 予定のカレンダーへ移る。

#### 2. 「取り込み」「要確認」「連携」を押す

1. 予定の取り込み、確認が必要な予定、カレンダーの連携の画面へ移る。

#### 3. 「照合」を押す

1. 照合の画面へ移る。

#### 4. 「職員」を押す

1. この画面を開き直す。

#### 5. 幅 768px 未満で、閉じるボタンか背景を押すか、Escape キーを押す

1. ナビゲーションのドロワーが閉じ、フォーカスがメニューのボタンに戻る。

## アカウント

**概要**: ログインしている職員を示し、名前とログアウトを入れたメニューを開く。

**値のソース**: 職員の名前の先頭の 1 文字を入れた丸と、職員の名前を並べたボタン。  
幅 768px 未満では、丸だけを出す。  
読み上げる名前は「アカウント（<職員の名前>）」にし、幅 768px 未満で名前を隠しても変えない。

**活性条件**: 常に活性

**表示条件**: ログインしているとき

**カタログ**: [ViewerMenu の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-viewermenu--default)

### インタラクション

#### 1. 押す

1. 職員の名前とログアウトのボタンを入れたメニューを、ボタンの下に開く。
2. もう一度押すか、メニューの外を押すか、Escape キーを押すと閉じる。

## ログアウト

**概要**: ログアウトする。

**値のソース**: 「ログアウト」

**活性条件**: 常に活性

**表示条件**: アカウントのメニューを開いている間。  
BFF を通して API を呼ぶ構成で、ログインしているとき

**カタログ**: [ViewerMenu の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-viewermenu--default)

### インタラクション

#### 1. 押す

1. ログアウトし、`/` へ移る。ログインしていないので、`/` からそのままログインの画面へ移る。

## ページのタイトル

**概要**: 何の画面かを示す。

**値のソース**: 「職員」

**活性条件**: 常に活性

**表示条件**: 職員の管理の権限を持つとき

## ヘルプ

**概要**: 休職と退職の職員の扱いを、見たいときに示す。  
形は [画面仕様書の規約の補足とヘルプ](../rules.md#補足とヘルプ) の ? のヘルプである。

**値のソース**: 「?」のボタン。読み上げる名前は「ヘルプ」。  
押すと、ページのタイトルの下に次の説明を出す。

| 説明 |
| --- |
| 「休職と退職の職員は、ログインできず、予定の担当の候補に出ません。」 |

**活性条件**: 常に活性

**表示条件**: 職員の管理の権限を持つとき。  
ページのタイトルの右に出す。

### インタラクション

#### 1. 押す

1. ページのタイトルの下に説明を開く。
2. もう一度押すか、説明の外を押すか、Escape キーを押すと閉じる。

## 職員を登録

**概要**: 新しい職員を登録する。

**値のソース**: 「職員を登録」

**活性条件**: 常に活性

**表示条件**: 職員の管理の権限を持つとき。  
ページのタイトルの行の右端に出す。

### インタラクション

#### 1. 押す

1. [職員の登録](../staff-new_職員の登録/index.md) を、この画面の上に重ねて開く。

## 名前の検索

**概要**: 名前の一部で職員を絞り込む。

**値のソース**: 欄の中の「名前で検索」。  
最初は空。

**活性条件**: 常に活性

**表示条件**: 職員を読み終えたとき

### インタラクション

#### 1. 名前の一部を入れる

1. 入れた文字を名前に含む職員だけを一覧に出し、人数を出し直す。空白の違いは無視する。
2. 合う職員がいなければ、「絞り込みで 0 件」の状態にする。

## 部署、チーム、役職の絞り込み

**概要**: 部署、チーム、役職で職員を絞り込む。

**値のソース**: 「部署: すべて」「チーム: すべて」「役職: すべて」のセレクト。  
選択肢は、「すべて」と、事業所の部署、チーム、役職の名前である。  
値を選んだセレクトは、枠を太くし、「部署: 看護部」のように選んだ名前を出す。

**活性条件**: 選択肢を読み終えたとき

**表示条件**: 職員を読み終えたとき

### インタラクション

#### 1. 値を選ぶ

1. 選んだ値の職員だけを一覧に出し、人数を出し直す。ほかの絞り込みと名前の検索と、同時に満たす職員だけを出す。
2. 合う職員がいなければ、「絞り込みで 0 件」の状態にする。

## 状態の絞り込み

**概要**: 在籍の職員だけを出すか、退職の職員も出すかを選ぶ。

**値のソース**: 次の選択肢のセレクト。  
最初は「在籍」を選び、枠を太くする。

| 選択肢 | 出す職員 |
| --- | --- |
| 「在籍」 | 有効と休職の職員 |
| 「有効」 | 有効の職員 |
| 「休職」 | 休職の職員 |
| 「退職」 | 退職の職員 |
| 「すべて」 | 全ての職員 |

**活性条件**: 常に活性

**表示条件**: 職員を読み終えたとき

### インタラクション

#### 1. 値を選ぶ

1. 選んだ状態の職員だけを一覧に出し、人数を出し直す。「すべて」を選ぶと「退職の職員も出す」の状態にする。
2. 合う職員がいなければ、「絞り込みで 0 件」の状態にする。

**値のソース**: 「5 人」の形の人数

**活性条件**: 常に活性

**表示条件**: 職員を読み終えたとき。

## 職員の一覧

**概要**: 絞り込んだ職員を、所属と在籍の状態とともに示す。

**値のソース**: 「名前」「部署」「チーム」「役職」「状態」のカラム。  
行は職員の名前の順に並べる。  
退職した職員の部署、チーム、役職は、退職したときの値を出す。  
幅 768px 未満では、カラムの名前を出さない。

**活性条件**: 常に活性

**表示条件**: 職員を読み終え、絞り込みに合う職員がいるとき

## 職員の行

**概要**: 職員を 1 人示し、押すとその職員の詳細を開く。

**値のソース**: 名前のカラムに、名前の先頭の 1 文字を入れた丸と、名前と、その下のメールアドレスを出す。  
退職の職員は、丸を薄い面にし、メールアドレスの代わりに「メールアドレスなし」を出す。  
行の右端に「›」を出す。  
幅 768px 未満では、1 行目に名前と状態の印を、2 行目に部署、チーム、役職を「・」でつなげて出し、丸とメールアドレスを出さない。

**活性条件**: 常に活性

**表示条件**: 職員の一覧の行ごとに出す。

## 全体動作

### 初期処理

- 開くと、ログインした職員の権限を読む。職員の管理の権限が無ければ、ほかの API を呼ばず、「権限が無い」の状態にする。
- 権限があれば、事業所の全ての職員と、部署、チーム、役職の選択肢を読み、職員を読み終えるまで「読み込み中」の状態にする。
  - 読めなかったときは、「読み込みの失敗」の状態にする。
- URL の search params は読まない。

### 絞り込み

名前の検索と、部署、チーム、役職、状態の絞り込みは、読んだ全ての職員を画面で絞り込む。  
絞り込むたびに API を呼び直さない。  
絞り込みの値は、詳細から一覧へ戻ると、開いた直後の値に戻る。

### 権限の確認

画面の判定は表示のためだけにする。  
予定の API も、職員の管理の権限が無い職員の変更のリクエストを 403 で拒む。

## 未決

- 職員の管理の権限を持たない職員が、同じ事業所の職員の連絡先を見る画面は無い。要るかは、プロフィールの画面を作るときに決める。
- 絞り込みの値を URL の search params に残すかは決めていない。詳細から戻ったときに絞り込みを保つ要望が出たら決める。
