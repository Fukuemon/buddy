# patient-list 利用者の一覧

職員の管理の権限を持つ職員が、事業所の利用中の利用者を、担当の職員、サービス、希望とともに一覧し、登録と詳細へ移る画面。  
利用の終了の利用者は、状態の絞り込みで出す。

| 項目 | 値 |
| --- | --- |
| URL | `/patients` |
| 使う人 | 職員の管理の権限を持つ職員。デフォルトはマネージャー |
| 実装 | `apps/web/src/routes/patients.tsx`、`apps/web/src/features/patient/components/PatientListContainer.tsx`、`apps/web/src/features/patient/components/PatientListView.tsx`、`packages/ui/src/base/RowTable/RowTable.tsx`、`packages/ui/src/case/ListTools/ListTools.tsx`、`apps/web/src/components/page/PageForbiddenMessage.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。  
カラム、絞り込み、並び順は、[使う場面](#使う場面) から決めた。

ADR-0021: [利用者を、戻せる利用の終了にでき、終了の利用者を予定の候補と職員の退職の確認から外す](../../adr/0021-patient-service-end.md)

## 構成

ヘッダーとナビゲーションは、[職員の一覧](../staff-list_職員の一覧/index.md#構成) と同じ形にする。  
ナビゲーションの見出しと項目、出す職員は、[職員の一覧のナビゲーション](../staff-list_職員の一覧/index.md#ナビゲーション) にある。  
今の画面の利用者に印を付ける。  
ナビゲーションの印は、幅 768px 未満ではドロワーを開くと出る。

ヘッダーの下の、ナビゲーションの右に、ページのタイトルとヘルプと利用者を登録のボタン、名前の検索と絞り込みと人数、利用者の一覧を縦に並べる。  
利用者の一覧は、[画面仕様書の規約の一覧](../rules.md#一覧) の形にする。  
幅 768px 以上では、行全体を押せる表にする。  
幅 768px 未満では、1 行目に名前、2 行目に担当の職員、サービス、希望の時間帯、希望する担当の性別を「・」でつなげた 2 行のリストにする。  
利用の終了の利用者を出すときは、利用の終了にした日を、1 行目の名前の右に出す。  
ヘルプの説明の印は、ヘルプを開くと出る。

## メニュー

**概要**: ナビゲーションの形を切り替える。  
幅 768px 未満では、ナビゲーションのドロワーを開く。

**値のソース**: 3 本の横線のアイコン。  
読み上げる名前は「メニュー」。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの左端に出す。

**カタログ**: [SiteLayoutContainer の Mobile](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitelayoutcontainer--mobile)

### インタラクション

#### 1. 幅 768px 以上で押す

1. ナビゲーションを、開いた形からレールに切り替える。
  - もう一度押すと開いた形に戻る。

#### 2. 幅 768px 未満で押す

1. 左端からナビゲーションのドロワーが開く。

## ナビゲーション

**概要**: 予定、照合、職員、利用者の画面の間を移る。

**値のソース**: 見出しと項目、出す職員は、[職員の一覧のナビゲーション](../staff-list_職員の一覧/index.md#ナビゲーション) にある。  
この画面では「利用者」に今の画面の印を付ける。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの下の左端に出す。  
幅 768px 以上では、この画面では開いた形で始める。  
幅 768px 未満では、メニューのボタンで開いたドロワーの中に出す。

**カタログ**: [SiteNav の Manager](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitenav--manager)

### インタラクション

#### 1. 項目を押す

1. 押した項目の画面へ移る。
  - 「利用者」を押すと、この画面を開き直す。

#### 2. 幅 768px 未満で、閉じるボタンか覆いを押すか、Escape キーを押す

1. ナビゲーションのドロワーが閉じ、フォーカスがメニューのボタンに戻る。

## アカウント

**概要**: ログインしている職員を示し、名前とログアウトを入れたメニューを開く。

**値のソース**: 職員の名前の先頭の 1 文字を入れた丸と、職員の名前を並べたボタン。  
幅 768px 未満では、丸だけを出す。  
読み上げる名前は「アカウント（<職員の名前>）」にする。  
幅 768px 未満で名前を隠しても、読み上げる名前は変えない。

**活性条件**: 常に活性

**表示条件**: ログインしているとき

**カタログ**: [ViewerMenu の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-viewermenu--default)

### インタラクション

#### 1. 押す

1. 職員の名前とログアウトのボタンを入れたメニューを、ボタンの下に開く。
2. もう一度押すか、メニューの外を押すか、Escape キーを押すと閉じる。

## 名前の検索

**概要**: 名前の一部で利用者を絞り込む。

**値のソース**: 欄の中の「名前で検索」。

**活性条件**: 常に活性

## 担当の職員の絞り込み

**概要**: 担当の職員で利用者を絞り込む。  
職員を退職にする前に、その職員が担当する利用者を探すときに使う。

**値のソース**: 「担当の職員: すべて」のセレクト。  
選択肢には、「すべて」と、読んだ利用者の担当の職員の名前を出す。  
休職か退職の職員も、担当の職員なら選択肢に出す。  
値を選んだセレクトは、枠を太くし、「担当の職員: 森 健太」のように選んだ名前を出す。

**活性条件**: 常に活性

**表示条件**: 利用者を読み終えたとき

### インタラクション

#### 1. 値を選ぶ

1. 選んだ職員が担当の利用者だけを一覧に出し、人数を出し直す。
  - 状態の絞り込みと名前の検索と、同時に満たす利用者だけを出す。
2. 合う利用者がいなければ、「絞り込みで 0 件」の状態にする。

## 状態の絞り込み

**概要**: 利用中の利用者だけを出すか、利用の終了の利用者を出すかを選ぶ。

**値のソース**: 次の選択肢のセレクト。  
最初は「利用中」を選ぶ。  
「利用中」のほかを選んだときだけ、枠を太くする。

| 選択肢 | 出す利用者 | 一覧に足すカラム |
| --- | --- | --- |
| 「利用中」 | 利用中の利用者 | なし |
| 「利用の終了」 | 利用の終了の利用者 | 「利用の終了にした日」 |
| 「すべて」 | 全ての利用者 | 「状態」 |

「すべて」を選んだときの「状態」のカラムには、利用の終了の行にだけ「利用の終了（2026/09/30）」の印を薄い面の色で出し、利用中の行には印を出さない。  
「すべて」の状態のモックは無い。

**活性条件**: 常に活性

**表示条件**: 利用者を読み終えたとき

### インタラクション

#### 1. 値を選ぶ

1. 選んだ状態の利用者だけを一覧に出し、人数を出し直す。
  - 「利用の終了」を選ぶと「利用の終了の利用者」の状態にする。
2. 合う利用者がいなければ、「絞り込みで 0 件」の状態にする。

## 利用者の一覧

**概要**: 絞り込んだ利用者を、担当の職員、サービス、希望とともに示す。

**値のソース**: 「名前」「担当の職員」「サービス」「希望の時間帯」「希望する担当の性別」のカラム。

## 全体動作

### 使う場面

利用者の一覧は、職員の管理の権限を持つ職員が、次の場面で開く。  
デフォルトでは、マネージャーが職員の管理の権限を持つ。  
場面は、[PRD の事業所と職員の要件](../../PRD.md#事業所と職員) と、[職員の一覧の使う場面](../staff-list_職員の一覧/index.md#使う場面) から書き出した。

| 場面 | 頻度 | 一覧に要る情報 |
| --- | --- | --- |
| 利用者を探して詳細を開き、担当の職員とサービスを変える | 週に数回 | 名前。同じ名字の利用者を見分ける担当の職員 |
| 職員の休職と退職の前に、その職員が担当する利用者を探し、担当を移す | 月に数回 | 担当の職員の絞り込み、担当の職員 |
| 訪問の割り振りで、担当の職員、サービス、希望を見る | 週に数回 | 担当の職員、サービス、希望の時間帯、希望する担当の性別 |
| 新しい利用者を登録し、一覧に出たことを見る | まれ（契約のとき） | 登録のボタン、名前 |
| 入院の後に訪問を再開する利用者を探し、利用を再開する | まれ | 利用の終了の利用者だけ、利用の終了にした日 |

### 決めたこと

場面から、カラム、絞り込み、並び順、デフォルトの表示を次のとおり決めた。

- デフォルトは利用中の利用者だけを出し、状態のカラムを出さない。
  - 利用の終了の利用者を見る場面は、利用を再開するときと過去を確認するときに限られ、まれだからである。
- 利用の終了の利用者は、状態の絞り込みで出し、利用の終了にした日のカラムを足す。
  - どの行も同じ状態になるので、状態の文字は繰り返さない。
- カラムは、名前、担当の職員、サービス、希望の時間帯、希望する担当の性別の順にする。
  - 週に数回の場面が、名前の次に担当の職員を見るためである。
- 担当の職員のチームの色の点は置かない。
  - 利用者はチームを持たず、点を置くと、利用者のチームと担当の職員のチームのどちらを示すかが紛れる。
  - 担当の職員ごとに見る場面は、担当の職員の絞り込みで見る。
- 並び順は、名前の順にする。
  - 利用者を探す場面は名前の検索で探し、担当の職員ごとに見る場面は絞り込みで見るので、並びで担当をまとめなくてよい。
- 絞り込みは、名前の検索、担当の職員、状態の順に置き、カラムの順にそろえる。

### 初期処理

- 職員の管理の権限を持たない職員には、利用者を読まずに「権限が無い」の状態を出す。
- 権限を持つ職員には、利用の終了の利用者を含む事業所の全ての利用者と、担当の職員の状態を読み終えるまで、「読み込み中」の状態を出す。
  - 読めなかったときは、「読み込みの失敗」の状態にする。
- URL の search params は読まない。

### 絞り込み

名前の検索と、担当の職員と状態の絞り込みは、開いたときに読んだ全ての利用者から絞り込む。  
絞り込んでも、利用者を読み直さず、「読み込み中」の状態にしない。  
絞り込みの値は、詳細から一覧へ戻ると、開いた直後の値に戻る。

### 権限の確認

職員の管理の権限を持たない職員には、「権限が無い」の状態を出す。  
画面を開いた後に職員の管理の権限を外された職員が利用者を登録すると、[利用者の登録の登録の失敗の文](../patient-new_利用者の登録/index.md#登録の失敗の文) に「この操作をする権限がありません。」を出す。  
権限で許す操作は、[権限の Design Doc の予定の認可](https://github.com/Fukuemon/buddy/blob/develop/services/schedule/internal/access/DesignDoc.md#予定の認可) にある。

  - 今の動き: 絞り込まない。
  - 決める人: 開発者
