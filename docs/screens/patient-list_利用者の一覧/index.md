# patient-list 利用者の一覧

職員の管理の権限を持つ職員が、事業所の利用者を、サービス、希望、担当の職員、利用の状態とともに一覧し、登録と詳細へ移る画面。  
利用の終了の利用者は、状態の絞り込みで出す。

| 項目 | 値 |
| --- | --- |
| URL | `/patients` |
| 使う人 | 職員の管理の権限を持つ職員（デフォルトはマネージャー） |
| 実装 | 未実装 |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

ADR-0021: [利用者を、戻せる利用の終了にでき、終了の利用者を予定の候補と職員の退職の確認から外す](../../adr/0021-patient-service-end.md)

## 構成

ヘッダーとナビゲーションは、[職員の一覧](../staff-list_職員の一覧/index.md#構成) と同じ形にし、見出し「職員」のまとまりの下に、見出し「利用者」のまとまりを足す。  
見出し「利用者」の下には、利用者を置く。  
見出し「利用者」のまとまりは、職員の管理の権限を持つ職員にだけ出す。  
今の画面の利用者に印を付ける。  
ナビゲーションの印は、幅 768px 未満ではドロワーを開くと出る。

ヘッダーの下の、ナビゲーションの右に、ページのタイトルとヘルプと利用者を登録のボタン、名前の検索と絞り込みと人数、利用者の一覧を縦に並べる。  
利用者の一覧は、[画面仕様書の規約の一覧](../rules.md#一覧) の形にする。  
幅 768px 以上では、行全体を押せる表にする。  
幅 768px 未満では、1 行目に名前と、利用の終了の利用者なら状態の印、2 行目にサービス、希望の時間帯、希望する担当の性別、担当の職員を「・」でつなげた 2 行のリストにする。  
ヘルプの説明の印は、ヘルプを開くと出る。

## メニュー

**概要**: ナビゲーションの形を切り替える。  
幅 768px 未満では、ナビゲーションのドロワーを開く。

**値のソース**: 3 本の横線のアイコン。  
読み上げる名前は「メニュー」。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの左端に出す。

**カタログ**: [SiteLayoutContainer の Mobile](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitelayoutcontainer--mobile)

### インタラクション

#### 1. 幅 768px 以上で押す

1. ナビゲーションを、開いた形からレールに切り替える。もう一度押すと開いた形に戻る。

#### 2. 幅 768px 未満で押す

1. 左端からナビゲーションのドロワーが開く。

## ナビゲーション

**概要**: 予定、照合、職員、利用者の画面の間を移る。

**値のソース**: [職員の一覧のナビゲーション](../staff-list_職員の一覧/index.md#ナビゲーション) の項目に、見出し「利用者」と、その下の家と人のアイコンと「利用者」を足す。  
見出し「利用者」のまとまりは、見出し「職員」のまとまりの下に置く。  
この画面では「利用者」に今の画面の印を付ける。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの下の左端に出す。  
幅 768px 以上では、この画面では開いた形で始める。  
幅 768px 未満では、メニューのボタンで開いたドロワーの中に出す。  
「取り込み」「要確認」「連携」と、見出し「職員」と「利用者」のまとまりは、職員の管理の権限を持つ職員にだけ出す。

**カタログ**: [SiteNav の Manager](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitenav--manager)

### インタラクション

#### 1. 項目を押す

1. 押した項目の画面へ移る。「利用者」を押すと、この画面を開き直す。

#### 2. 幅 768px 未満で、閉じるボタンか背景を押すか、Escape キーを押す

1. ナビゲーションのドロワーが閉じ、フォーカスがメニューのボタンに戻る。

## アカウント

**概要**: ログインしている職員を示し、名前とログアウトを入れたメニューを開く。

**値のソース**: 職員の名前の先頭の 1 文字を入れた丸と、職員の名前を並べたボタン。  
幅 768px 未満では、丸だけを出す。  
読み上げる名前は「アカウント（<職員の名前>）」にし、幅 768px 未満で名前を隠しても変えない。

**活性条件**: 常に活性

**表示条件**: ログインしているとき

**カタログ**: [ViewerMenu の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-viewermenu--default)

### インタラクション

#### 1. 押す

1. 職員の名前とログアウトのボタンを入れたメニューを、ボタンの下に開く。
2. もう一度押すか、メニューの外を押すか、Escape キーを押すと閉じる。

1. ログアウトし、`/` へ移る。ログインしていないので、`/` からそのままログインの画面へ移る。

## ヘルプ

**値のソース**: 「?」のボタン。読み上げる名前は「ヘルプ」。

| --- |
| 「利用の終了の利用者は、予定の利用者の候補に出ません。」 |

**活性条件**: 常に活性

**表示条件**: 職員の管理の権限を持つとき。  
ページのタイトルの右に出す。

#### 1. 押す

1. ページのタイトルの下に説明を開く。
2. もう一度押すか、説明の外を押すか、Escape キーを押すと閉じる。

## 名前の検索

**概要**: 名前の一部で利用者を絞り込む。

**値のソース**: 欄の中の「名前で検索」。  
最初は空。

**活性条件**: 常に活性

**表示条件**: 利用者を読み終えたとき

### インタラクション

#### 1. 名前の一部を入れる

1. 入れた文字を名前に含む利用者だけを一覧に出し、人数を出し直す。空白の違いは無視する。
2. 合う利用者がいなければ、「絞り込みで 0 件」の状態にする。

## 担当の職員の絞り込み

**概要**: 担当の職員で利用者を絞り込む。  
職員を退職にする前に、その職員が担当する利用者を探すときに使う。

**値のソース**: 「担当の職員: すべて」のセレクト。  
選択肢は、「すべて」と、読んだ利用者の担当の職員の名前である。休職か退職の職員も、担当の職員なら選択肢に出す。  
値を選んだセレクトは、枠を太くし、「担当の職員: 森 健太」のように選んだ名前を出す。

**活性条件**: 常に活性

**表示条件**: 利用者を読み終えたとき

### インタラクション

#### 1. 値を選ぶ

1. 選んだ職員が担当の利用者だけを一覧に出し、人数を出し直す。状態の絞り込みと名前の検索と、同時に満たす利用者だけを出す。
2. 合う利用者がいなければ、「絞り込みで 0 件」の状態にする。

## 状態の絞り込み

**概要**: 利用中の利用者だけを出すか、利用の終了の利用者も出すかを選ぶ。

**値のソース**: 次の選択肢のセレクト。  
最初は「利用中」を選び、枠を太くする。

| 選択肢 | 出す利用者 |
| --- | --- |
| 「利用中」 | 利用中の利用者 |
| 「利用の終了」 | 利用の終了の利用者 |
| 「すべて」 | 全ての利用者 |

**活性条件**: 常に活性

**表示条件**: 利用者を読み終えたとき

### インタラクション

#### 1. 値を選ぶ

1. 選んだ状態の利用者だけを一覧に出し、人数を出し直す。「すべて」を選ぶと「利用の終了の利用者も出す」の状態にする。
2. 合う利用者がいなければ、「絞り込みで 0 件」の状態にする。

## 人数

**概要**: 絞り込んだ後に一覧に出ている利用者の人数を示す。

**値のソース**: 「3 人」の形の人数

**活性条件**: 常に活性

**表示条件**: 利用者を読み終えたとき。  
絞り込みの行の右端に出す。

## 利用者の一覧

**概要**: 絞り込んだ利用者を、サービス、希望、担当の職員、利用の状態とともに示す。

**値のソース**: 「名前」「サービス」「希望の時間帯」「希望する担当の性別」「担当の職員」「状態」のカラム。  
サービスはサービスコード（「訪看I2」など）を出す。  
希望の時間帯は「午前」か「午後」を、希望する担当の性別は「男性」か「女性」を出す。  
担当の職員が休職なら「小野 拓海（休職）」、退職なら「西村 学（退職）」のように、名前の後ろに状態を括弧で付ける。休職か退職の職員が担当のままの利用者に気付けるようにするためである。  
行は利用者の名前の順に並べる。  
幅 768px 未満では、カラムの名前を出さない。

**活性条件**: 常に活性

## 全体動作

### 初期処理

- 開くと、ログインした職員の権限を読む。職員の管理の権限が無ければ、ほかの API を呼ばず、「権限が無い」の状態にする。
- 権限があれば、利用の終了の利用者を含む事業所の全ての利用者と、担当の職員の状態を出すための事業所の職員を読み、読み終えるまで「読み込み中」の状態にする。
  - 読めなかったときは、「読み込みの失敗」の状態にする。
- URL の search params は読まない。

### 絞り込み

名前の検索と、担当の職員と状態の絞り込みは、読んだ全ての利用者を画面で絞り込む。  
絞り込むたびに API を呼び直さない。  
絞り込みの値は、詳細から一覧へ戻ると、開いた直後の値に戻る。

### 権限の確認

画面の判定は表示のためだけにする。  
予定の API も、職員の管理の権限が無い職員の変更のリクエストを 403 で拒む。

## 未決

- 絞り込みの値を URL の search params に残すかは決めていない。職員の一覧と同じく、詳細から戻ったときに絞り込みを保つ要望が出たら決める。
- 希望の時間帯と希望する担当の性別で絞り込むかは決めていない。予定の API の利用者の一覧は、この 2 つの絞り込みを持つ。担当の割り振りに使う要望が出たら足す。
