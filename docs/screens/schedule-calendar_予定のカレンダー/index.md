# schedule-calendar 予定のカレンダー

職員が、事業所の職員の予定を月、週、日の表示で見て、予定の作成と詳細を開く画面。表示する職員を、チームと職員のチェックボックスで絞り込む。

| 項目 | 値 |
| --- | --- |
| URL | `/schedule`。`/` を開くと `/schedule` へ転送する |
| 使う人 | 全ての職員。表示する予定は、閲覧の権限の範囲で決まる |
| 実装 | `apps/web/src/routes/schedule.tsx`、`apps/web/src/features/schedule/components/ScheduleCalendarContainer.tsx`、`apps/web/src/features/schedule/components/StaffFilterLayout.tsx`、`apps/web/src/features/schedule/components/StaffFilterSidebarContainer.tsx`、`apps/web/src/components/site/SiteHeaderContainer.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

## 構成

画面は、上端のヘッダー、左の職員の絞り込み、右のカレンダーの 3 つに分かれる。カレンダーの上に、表示する期間と表示の単位を変えるツールバーを置く。カレンダーの領域は、予定の一覧と職員の一覧の 2 つの取得の結果で表示を変える。

幅 768px 未満では、職員の絞り込みを左端から開くドロワーに入れ、閉じた状態で出す。モックのモバイルの表示では、ツールバーの「職員の絞り込み」でドロワーが開き、閉じるボタン、背景、Escape で閉じる。職員の絞り込みの中の要素とドロワーの閉じるボタンの印は、ドロワーを開くと出る。開くボタンとドロワーは、幅 768px 未満のときだけ出る。

## ナビゲーション

**概要**: 予定と照合の画面を行き来する。

**値のソース**: 「予定」と「照合」のリンク。この画面では「予定」を今の画面として示す。

**活性条件**: 常に活性

**表示条件**: 常に表示

**カタログ**: [SiteNav の Schedule](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitenav--schedule)

### インタラクション

#### 1. 「予定」を押す

1. `/schedule` を読み込み直す。search params は消え、今日の月の表示に戻る。

#### 2. 「照合」を押す

1. 照合の画面へ移る。

## カレンダー

**概要**: 月と週の表示で、予定を日と時刻の枠に置く。

**値のソース**: 月の表示は、月の初日を含む週の日曜から 6 週分の日付。週は日曜に始まる。週の表示は、日曜から 7 日分の日付と、6 時から 22 時の時刻。

- 今日の日付の枠は、月と週の表示で色を変える。
- 週の表示では、今の時刻の位置に横の線を引く。線は [今の時刻の線](#今の時刻の線) にある。

## 予定

**概要**: 1 件の予定を示し、詳細を開く。

**値のソース**: 時刻とタイトル。時刻の形は、表示の単位で違う。

- 月の表示は開始の時刻だけを出す。正時は「9時」、それ以外は「9:30」の形にする。
- 週の表示は、開始と終了の時刻を「9:00 - 9:30」の形で出す。
- 日の表示は、開始と終了の時刻を「09:00-09:30」の形で出す。

- タイトルは、訪問の予定なら「<利用者の名前> 訪問」、通常の予定なら予定のタイトルにする。利用者の一覧を取り終える前と、取得に失敗したときは「利用者不明 訪問」になる。
- 色は、職員の一覧の並びの位置で、区別の色の 10 色から決める。11 人目からは色が重なる。月と週の表示では、職員の一覧に無い職員の予定は灰色にする。日の表示は、職員の一覧に無い職員の列を持たないので、その予定を出さない。
- 週と日の表示では、予定の長さで高さが決まる。日の表示の高さは 20px 以上にする。30 分未満の予定は、押せる領域が 44px に届かない。

**活性条件**: 常に活性

**表示条件**: 予定が表示の期間に重なり、URL の `staff` が空か、`staff` に担当の職員を含むとき。

- キャンセルした予定は出さない。API につないだときの動きである。
- 繰り返しの予定は、表示の期間の回に分けて置く。除外した日（1 回だけ置き換えた日を含む）の回は置かない。回を押すとその回の詳細を開き、その回を編集すると、その回だけを単発の予定に置き換える。
- API につないだ後は、API が自分の予定を常に返す。画面の職員の絞り込みで自分を外すと、自分の予定も出さない。
- ほかの職員の予定は、事業所の全ての予定の閲覧、指定した職員の予定の閲覧、指定したチームの職員の予定の閲覧のどれかで対象のときだけ、API が返す。権限の名前は、PRD の役職ごとの権限にある 7 つの権限を指す。編集の権限は同じ範囲の閲覧を含む。
- 閲覧の権限が無い職員の予定は API が一覧から除き、画面は案内の文を出さない。

**カタログ**: [ScheduleCalendar の Month](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-schedulecalendar--month)、[StaffScheduleDayGrid の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-staffscheduledaygrid--default)

## 全体動作

### 初期処理

- 予定はブラウザだけで描き、サーバーは予定を描かない。
- 開いた直後のフォーカスは `body` にある。フォーカスを特定の要素へ移す処理は無い。
- 予定、職員、チーム、利用者の一覧を取る。取得が終わる前は、ツールバーの全ての操作と、絞り込んでいるときの「全員を表示」を受け付ける。カレンダーを出していないので、予定、空いた日、空いた時間、時間の枠は押せない。取得が終わった後は、全ての操作を受け付ける。
- 取得の失敗は、3 回まで取り直してから出す。
- BFF を通すときに API が 401 を返したら、今の画面に戻るログインの画面へ移る。フェイクの API は 401 を返さない。

### 履歴と、予定のモーダル

- URL を変える操作は、どれも履歴に積む。ブラウザの戻るで前の表示に戻る。
- 予定の作成、詳細、編集は、この画面の上にモーダルで重ねて出す。モーダルの URL は `/schedule` の子で、カレンダーの search params を引き継ぐ。

### 幅による配置

- 職員の絞り込みのチェックボックス、「全員を表示」、「職員の絞り込み」、ドロワーの閉じるボタン、空いた時間の枠、時間の枠の押せる領域は 44px 以上にする。予定の押せる領域は、予定の長さで決まる（[予定](#予定)）。

幅 768px 未満では、配置を次のように変える。ページは幅 320px でも横に送らない。

- 職員の絞り込みを、左端から開くドロワーに入れる。ドロワーは閉じた状態で始まり、ツールバーの「職員の絞り込み」で開く。
- ツールバーを折り返し、表示の単位を幅いっぱいにする。
- カレンダーの左右の余白を 8px にする。
- 日の表示の職員の列は、職員ごとの日の表の中で横に送る。

### URL の search params からの復元

読めない値はデフォルト値に置き換え、デフォルト値は URL から消す。

| search param | 値 | 省いたときと読めないとき |
| --- | --- | --- |
| `view` | `month`、`week`、`day` | `month` |
| `date` | `YYYY-MM-DD` | 今日 |
| `staff` | 職員の id の配列。JSON の配列を符号化した形で、`["staff-1","staff-2"]` は `staff=%5B%22staff-1%22%2C%22staff-2%22%5D` になる | 空の配列（全ての職員） |

## 未決

PRD と実装が食い違うところ。

- PRD は、初めて開いたときに見る権限がある職員の全部を出すとしている。実装は、フェイクの API の事業所の全ての職員を出す。職員の絞り込みに閲覧の権限の外の職員を出すかが決まっていない。
- PRD の時間外の勤務の印を、カレンダーに出していない。

決まっていないところ。

- 予定が 0 件のときに、案内の文を出すか。
- 403 と 404 も、取得の失敗として 3 回取り直してから出している。4xx を取り直さないかが決まっていない。
- 403 を、ほかの取得の失敗と同じ文で出すか、権限が無いことを示す文に分けるか。
- 週と日の表示は 6 時から 22 時だけを出す。夜勤のようにその外の時刻にかかる予定を、どう見せるか。
- 予定の一覧の期間と職員の絞り込みを、API で絞るか画面で絞るか。OpenAPI の予定の一覧は日付の範囲だけを受ける。
- 編集の権限が自分の予定だけの職員に、「予定を作成」と、ほかの職員の列の時間の枠を出すか。
- キャンセルした予定を、カレンダーに印を付けて出すか。今は出さない。
