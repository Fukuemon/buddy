# schedule-calendar 予定のカレンダー

職員が、事業所の職員の予定を月、週、日の表示で見て、予定の作成と詳細を開く画面。  
表示する職員を、チームと職員のチェックボックスで絞り込む。

| 項目 | 値 |
| --- | --- |
| URL | `/schedule`。`/` を開くと `/schedule` へリダイレクトする |
| 使う人 | 全ての職員。表示する職員と予定は、予定を見る権限の範囲で決まる |
| 実装 | `apps/web/src/routes/schedule.tsx`、`apps/web/src/features/schedule/components/SchedulePageLayout.tsx`、`apps/web/src/features/schedule/components/ScheduleCalendarContainer.tsx`、`apps/web/src/features/schedule/components/ScheduleCancelledToggleContainer.tsx`、`apps/web/src/features/schedule/components/StaffFilterSidebarContainer.tsx`、`apps/web/src/features/schedule/components/ScheduleMiniCalendarContainer.tsx`、`apps/web/src/components/site/SiteLayoutContainer.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

## 構成

画面は、上端のヘッダー、左端のナビゲーション、左の欄、右のカレンダーの 4 つに分かれる。  
左の欄は、上からミニカレンダー、「キャンセルした予定を出す」、職員の絞り込みを並べ、それぞれの間を線で区切る。  
中身が入りきらないときは、左の欄の全体を 1 つの領域として縦に送る。  
カレンダーの上に、表示する期間と表示の単位を変えるツールバーを置く。  
ツールバーの右の表示の単位と「予定を作成」は、幅 768px 以上では、どの表示の単位でも表示の期間の見出しと同じ行に置く。  
カレンダーの領域は、予定の一覧と職員の一覧の 2 つの取得の結果で表示を変える。

ヘッダーの左に、メニューのボタンと buddy を置く。  
ヘッダーの右には、アカウントのボタンを置く。  
ヘッダーの下の左端には、画面の間を移るナビゲーションを置く。  
ナビゲーションは、見出し「予定」の下にカレンダー、取り込み、要確認、連携を並べ、見出し「照合」の下に照合を並べる。  
取り込み、要確認、連携は、職員の管理の権限を持つ職員にだけ出す。  
今の画面のカレンダーに印を付ける。  
幅 768px 以上では、ナビゲーションを幅 80px のレールで始め、メニューのボタンで幅 224px の開いた形と切り替える。  
幅 768px 未満では、ナビゲーションをドロワーにし、閉じた状態で始める。

ナビゲーションとカレンダーの間に、ミニカレンダー、キャンセルした予定の切り替え、職員の絞り込みを入れた、幅 288px の左の欄を置く。  
幅 768px 以上では、左の欄を開いた状態で始め、カレンダーのツールバーの「日付と絞り込み」のボタンでたたむ。  
たたむとカレンダーが左の欄の分だけ広がり、もう一度押すと開く。  
幅 768px 未満では、左の欄を「日付と絞り込み」のドロワーにし、閉じた状態で出す。  
モックのモバイルの表示では、同じボタンでドロワーが開き、閉じるボタン、覆い、Escape で閉じる。

幅 768px 未満では、ドロワーの中の並びも、幅 768px 以上の左の欄と同じにする。  
モックのモバイルの表示では、ミニカレンダーの日を押してもドロワーが閉じる。  
左の欄を閉じるボタンと、左の欄の要素の印は、幅 768px 未満では「日付と絞り込み」のドロワーを開くと出る。  
ナビゲーション、要確認、取り込みの印は、幅 768px 未満ではメニューのボタンでナビゲーションのドロワーを開くと出る。

モックは、事業所の全ての予定を編集できる職員の画面を描く。  
予定を見る権限と編集する権限で、職員の絞り込み、職員の列、「予定を作成」、時間の枠の出し方が変わる。  
出し方は、[権限の確認](#権限の確認) にある。

**値のソース**: 3 本の横線のアイコン。  
読み上げる名前は「メニュー」。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの左端に出す。

### インタラクション

#### 1. 幅 768px 以上で押す

1. ナビゲーションを、レールから開いた形に切り替える。
   - もう一度押すとレールに戻る。

#### 2. 幅 768px 未満で押す

1. 左端からナビゲーションのドロワーが開く。

## ナビゲーション

**概要**: 予定と照合の画面の間を移る。

**値のソース**: 見出し「予定」の下に、「カレンダー」「取り込み」「要確認」「連携」のアイコンと名前を並べる。  
見出し「照合」の下に、「照合」のアイコンと名前を置く。  
今の画面に面の色の印を付ける。  
この画面では「カレンダー」に付ける。  
レールでは見出しを出さず、アイコンの下に名前を置き、「予定」と「照合」の間を区切り線で分ける。

**活性条件**: 常に活性

**表示条件**: 常に、ヘッダーの下の左端に出す。  
幅 768px 以上では、この画面ではレールで始める。  
幅 768px 未満では、メニューのボタンで開いたドロワーの中に出す。  
「取り込み」「要確認」「連携」は、職員の管理の権限を持つ職員にだけ出す。  
見出し「照合」と「照合」は、照合の権限を持つ職員にだけ出す。  
モックは、職員の管理の権限を持つ職員の画面を描く。

**カタログ**: [SiteNav の Rail](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitenav--rail)

### インタラクション

#### 1. 「カレンダー」を押す

1. `/schedule` を読み込み直す。
   - search params は消え、今日の月の表示に戻る。

#### 2. 「連携」を押す

1. カレンダーの連携の画面へ移る。

#### 3. 「照合」を押す

1. 照合の画面へ移る。

#### 4. 幅 768px 未満で、閉じるボタンか覆いを押すか、Escape キーを押す

1. ナビゲーションのドロワーが閉じ、フォーカスがメニューのボタンに戻る。

  - 両方に予定の全体の時刻を出し、終了の時刻の前に「翌」を付ける。
    - 週の表示は「22:00 - 翌 1:00」、日の表示は「22:00-翌 01:00」の形にする。

  - 月と週の表示では、職員の一覧に無い職員の予定は灰色にする。

- 週と日の表示では、予定の長さで高さが決まる。
  - 日の表示の高さは 20px 以上にする。

  - 面を薄い灰色にし、取り消し線を付ける。
  - 「キャンセル」の文字は画面に出さず、読み上げの文にだけ置く。狭いマスで、予定の名前を押し出さないためである。
  - 職員の色は、月と週では枠に、日では左の線に残す。
  - 日の表示では、同じ時刻の予定と空いた枠を隠さないよう、列の左の半分に置き、生きている予定より下に描く。

- 予定を見る権限による出し分けは、[権限の確認](#権限の確認) にある。

**活性条件**: [予定を作成](#予定を作成) を出す職員のとき。  
出さない職員が押しても、何も起きない

**表示条件**: 表示の単位が週で、予定と職員の取得が成功したとき

**カタログ**: [ScheduleCalendar の Week](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-schedulecalendar--week)

### インタラクション

#### 1. 押す

1. 予定の作成をこの画面の上に開く。
   - URL は `/schedule/new?start=<日付>&time=<時刻>` に、カレンダーの search params を足したものにする。

## 職員ごとの日の表

**概要**: 日の表示で、1 日の予定を職員ごとの列に並べる。

**値のソース**: 左端の時刻の列と、職員の列。  
時刻の列には「00:00」から「23:00」を並べる。  
0 時から 24 時を 30 分の枠で区切る。  
開いたときと日を変えたときは 6 時の位置を出し、上へ送ると 0 時、下へ送ると 24 時までを出す。

**活性条件**: 常に活性

**表示条件**: 表示の単位が日で、予定と職員の取得が成功したとき。  
職員の列が入りきらないときは、表の中で横に送る

**カタログ**: [StaffScheduleDayGrid の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-staffscheduledaygrid--default)

## 職員の列

**概要**: どの職員の列かを示す。

**値のソース**: 列の見出しに職員の名前。

**活性条件**: 常に活性

**表示条件**: URL の `staff` が空なら、ログインした職員が予定を見られる全ての職員、空でなければ `staff` に含まれる職員の分を、職員の一覧の順に出す。  
休職と退職の職員と、訪問しない職員と、ログインした職員が予定を見られない職員の列は、`staff` に含まれていても出さない

**カタログ**: [StaffScheduleDayGrid の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-staffscheduledaygrid--default)、[ScheduleCalendarContainer の DaySelfEditOnly](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-schedulecalendarcontainer--day-self-edit-only)

## 職員の予定の列

**概要**: 職員の時間の枠と予定を縦に並べる。

**値のソース**: その職員の時間の枠と予定。

**活性条件**: 常に活性

**表示条件**: 職員の列と同じ

**カタログ**: [StaffScheduleDayGrid の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-staffscheduledaygrid--default)

## 時間の枠

**値のソース**: 30 分の枠。  
読み上げの名前は「<職員の名前> <時刻> に予定を作成」。

**活性条件**: ログインした職員が、その列の職員の予定を編集できるとき。  
ほかの列の枠はボタンにせず、押しても何も起きない。  
ほかの列の枠は、読み上げの名前も持たない

**表示条件**: 表示の単位が日で、予定と職員の取得が成功したとき

**カタログ**: [StaffScheduleDayGrid の Default](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-staffscheduledaygrid--default)、[ScheduleCalendarContainer の DaySelfEditOnly](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-schedulecalendarcontainer--day-self-edit-only)

## 今の時刻の線

**概要**: 週と日の表示で、今の時刻の位置を示す。

**値のソース**: デバイスの今の時刻。  
1 分ごとに位置を動かす。

- 週の表示では今日の列に、日の表示では全ての職員の列に、横の線を `primary` の色で引く。
  - `danger` はエラーと紛れるので使わない。
- 飾りなので、読み上げない。

**活性条件**: 押せない。  
線の下の時間の枠と予定を押せる

**表示条件**: 表示している期間に今日が含まれるとき。  
日の表示では、職員の列があるとき

**カタログ**: [ScheduleCalendar の Week](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-schedulecalendar--week)、[StaffScheduleDayGrid の WithNow](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-staffscheduledaygrid--with-now)

## 読み込み中の表示

**概要**: カレンダーを読み込んでいることを示す。

**値のソース**: 「カレンダーを表示中...」

**活性条件**: 常に活性

**表示条件**: 予定か職員を読み終えていないとき。

**概要**: 予定か職員を読めなかったことを伝える。

**活性条件**: 常に活性

**表示条件**: 予定か職員を読めなかったとき。

## 全体動作

### 初期処理

予定、職員、チーム、利用者の一覧を読む。  
読む順と失敗の扱いは、[予定の管理の Design Doc の予定の画面の読み込みと保存](https://github.com/Fukuemon/buddy/blob/develop/services/schedule/DesignDoc.md#予定の画面の読み込みと保存) にある。

- 読み終える前は、ツールバーの全ての操作、ミニカレンダー、「キャンセルした予定を出す」、名前の検索、絞り込んでいるときの「全員を表示」を受け付ける。
  - カレンダーを出していないので、予定、空いた日、空いた時間、時間の枠は押せない。
- 読み終えた後は、全ての操作を受け付ける。
- つながらないときは、何度か読み直してから「読み込みの失敗」の状態を出す。
  - 読み直しても変わらない失敗では、すぐに出す。
- ログインが切れていたら、今の画面に戻るログインの画面へ移る。

職員の一覧は、休職と退職の職員と、訪問しない職員も含めて読む。  
休職と退職の職員と、訪問しない職員は、職員の絞り込み、職員の列、予定から除き、残りの職員の並びは変えない。

予定が無い期間でも、案内の文は出さない。  
この表示は「予定が無い」の状態に当たる。

開いた直後のフォーカスは `body` にある。  
フォーカスを特定の要素へ移さない。  
ミニカレンダーの日の表は Tab で 1 度だけ止まり、表の中は矢印のキーで動く。  
動き方は、[ミニカレンダーの日](#ミニカレンダーの日) にある。

### URL の search params からの復元

読めない値はデフォルト値に置き換え、デフォルト値は URL から消す。

| search param | 値 | 省いたときと読めないとき |
| --- | --- | --- |
| `view` | `month`、`week`、`day` | `month` |
| `date` | `YYYY-MM-DD` | 今日 |
| `staff` | 職員の id の配列。JSON の配列を符号化した形で、`["staff-1","staff-2"]` は `staff=%5B%22staff-1%22%2C%22staff-2%22%5D` になる。休職と退職の職員と、訪問しない職員の id は、職員の一覧を読んだ後に除く | 空の配列（全ての職員）。休職と退職の職員と、訪問しない職員の id だけのときも同じ |
| `cancelled` | `true`、`false` | `false`（キャンセルした予定を出さない） |

### 画面の移動と履歴

URL を変える操作は、どれも履歴に積む。  
ブラウザの戻るで前の表示に戻る。

予定の作成、詳細、編集は、この画面の上にモーダルで重ねて出す。  
モーダルの URL は `/schedule` の子で、カレンダーの search params を引き継ぐ。

### 幅による配置

「キャンセルした予定を出す」、職員の絞り込みのチェックボックス、「自分だけ」、「全員を表示」、名前の検索、前の月、次の月、空いた時間の枠、時間の枠の押せる領域は 44px 以上にする。  
ミニカレンダーの日は、押せる領域の高さを 44px にする。  
予定の押せる領域は、予定の長さで決まる。  
予定の高さの決まり方は、[予定](#予定) にある。

幅 768px 未満では、配置を次のように変える。  
ページは幅 320px でも横に送らない。

- ナビゲーションを、左端から開くドロワーにする。
  - ドロワーは閉じた状態で始まり、ヘッダーのメニューのボタンで開く。
- 左の欄を、左端から開く「日付と絞り込み」のドロワーにする。
  - ドロワーは閉じた状態で始まり、カレンダーのツールバーの「日付と絞り込み」のボタンで開く。
- ツールバーを折り返し、表示の単位を幅いっぱいにする。
- カレンダーの左右の余白を 8px にする。
- 日の表示の職員の列は、職員ごとの日の表の中で横に送る。

### 権限の確認

画面は、ログインした職員の予定の権限から、職員ごとに予定を見られるか、編集できるかを決める。  
規則は [画面仕様書の規約の権限の出し分け](../rules.md#権限の出し分け) にある。  
権限の名前は、PRD の役職ごとの権限にある 7 つの権限を指す。

- 予定を見られる職員は、自分と、次のどれかで対象の職員である。
  - 事業所の全ての予定の閲覧
  - 指定した職員の予定の閲覧
  - 指定したチームの職員の予定の閲覧
- 編集の権限は、同じ範囲の閲覧を含む。
- 職員の絞り込み、職員の列、予定には、予定を見られる職員だけを出す。
  - 休職と退職の職員と、訪問しない職員は、見られても除く。
  - 見られない職員の予定は出さず、案内の文も出さない。
- 自分の予定は、権限によらず出す。
  - 職員の絞り込みで自分を外すと、自分の予定も出さない。
- [予定を作成](#予定を作成) は、自分の予定の編集を含む、編集の権限を 1 つ以上持つ職員にだけ出す。
- 日の表示の [時間の枠](#時間の枠) は、ログインした職員が予定を編集できる職員の列でだけ押せる。
  - ほかの列の枠は、押しても何も起きない。
- 週の表示の [空いた時間](#空いた時間) は、「予定を作成」を出さない職員には、押しても何も起きない。
- 月の表示の [空いた日](#空いた日) は、権限によらず日の表示へ移る。
- ナビゲーションの「取り込み」「要確認」「連携」は職員の管理の権限を持つ職員に、「照合」は照合の権限を持つ職員にだけ出す。
  - 出し方は、[ナビゲーション](#ナビゲーション) にある。
