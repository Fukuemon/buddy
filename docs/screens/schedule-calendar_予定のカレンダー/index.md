# schedule-calendar 予定のカレンダー

職員が、事業所の職員の予定を月、週、日の表示で見て、予定の作成と詳細を開く画面。表示する職員を、チームと職員のチェックボックスで絞り込む。

| 項目 | 値 |
| --- | --- |
| URL | `/schedule`。`/` を開くと `/schedule` へリダイレクトする |
| 使う人 | 全ての職員。表示する予定は、閲覧の権限の範囲で決まる |
| 実装 | `apps/web/src/routes/schedule.tsx`、`apps/web/src/features/schedule/components/SchedulePageLayout.tsx`、`apps/web/src/features/schedule/components/ScheduleCalendarContainer.tsx`、`apps/web/src/features/schedule/components/ScheduleCancelledToggleContainer.tsx`、`apps/web/src/features/schedule/components/StaffFilterSidebarContainer.tsx`、`apps/web/src/features/schedule/components/ScheduleMiniCalendarContainer.tsx`、`apps/web/src/components/site/SiteLayoutContainer.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

## 構成

ヘッダーの左から、メニューのボタン、buddy、今の機能の名前「予定」を置く。ヘッダーの右には、左から取り込み、要確認、アプリ、アカウントのボタンを並べる。取り込みと要確認のボタンは、職員の管理の権限を持つ職員にだけ出す。アプリのボタンは、ボタンの下に「予定」「照合」を並べたメニューを開く。メニューのボタンは、ミニカレンダー、キャンセルした予定の切り替え、職員の絞り込みを入れた、幅 288px の左の欄を開閉する。幅 768px 以上では、左の欄を開いた状態で出し、閉じるとカレンダーを広げる。モックは閉じた状態を描かない。幅 768px 未満では、左の欄を「日付と絞り込み」のドロワーにし、閉じた状態で出す。モックのモバイルの表示では、メニューのボタンでドロワーが開き、閉じるボタン、背景、Escape で閉じる。

画面は、上端のヘッダー、左の欄、右のカレンダーの 3 つに分かれる。左の欄は、上からミニカレンダー、「キャンセルした予定を出す」、職員の絞り込みを並べ、それぞれの間を線で区切る。中身が入りきらないときは、左の欄の全体を 1 つの領域として縦に送る。カレンダーの上に、表示する期間と表示の単位を変えるツールバーを置く。ツールバーの右の表示の単位と「予定を作成」は、幅 768px 以上では、どの表示の単位でも表示の期間の見出しと同じ行に置く。カレンダーの領域は、予定の一覧と職員の一覧の 2 つの取得の結果で表示を変える。

幅 768px 未満では、ドロワーの中の並びも、幅 768px 以上の左の欄と同じにする。モックのモバイルの表示では、ミニカレンダーの日を押してもドロワーが閉じる。左の欄を閉じるボタンと、左の欄の要素の印は、幅 768px 未満ではドロワーを開くと出る。

## アプリ

**概要**: 予定と照合の画面を行き来するメニューを開く。

**値のソース**: 9 つの点のアイコン。読み上げる名前は「アプリ」。メニューには、「予定」「照合」のアイコンと名前を並べ、今の機能に面の色の印を付ける。この画面では「予定」に付ける。

**活性条件**: 常に活性

**表示条件**: ヘッダーの右の、アカウントの左に、常に出す。メニューは、押したときだけボタンの下に出す。

**カタログ**: [SiteNav の Schedule](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-common-sitenav--schedule)

### インタラクション

#### 1. 押す

1. ボタンの下に、「予定」「照合」を並べたメニューを開く。

#### 2. 「予定」を押す

1. `/schedule` を読み込み直す。search params は消え、今日の月の表示に戻る。

#### 3. 「照合」を押す

1. 照合の画面へ移る。

#### 4. メニューの外を押すか、Escape キーを押す

1. メニューを閉じる。

## 職員の名前の検索

**概要**: 職員の一覧を、名前に含む語で絞る。

**値のソース**: 入力した語。プレースホルダーは「名前で絞り込む」、読み上げの名前は「職員の名前で絞り込む」。

- 名前に語を含む職員だけを一覧に出し、その職員がいないチームは出さない。照合では、全角と半角をそろえ、空白を無視する。「青木一郎」でも「青木 一郎」に当たる。

- 語は URL に持たず、画面を開き直すと空に戻る。

**活性条件**: 常に活性

**表示条件**: 職員の絞り込みと同じ

**カタログ**: [StaffFilterSidebar の AllStaff](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-stafffiltersidebar--all-staff)

**概要**: チームの職員をまとめて選ぶ、外す。

**値のソース**: チームの名前。チームの職員が全員選ばれていれば印が付き、一部なら中間の印が付く。絞り込んでいないときは、職員が 1 人以上いるチームに全て付く。職員が 0 人のチームには、印が付かない。名前の検索の間も、検索で隠れた職員を含めて印を決める。

**活性条件**: 常に活性。ただし、外すと表示する職員が 0 人になる操作は受け付けない

**表示条件**: チームの取得が成功したとき。チームの下の職員は、職員の取得が成功した後に出る。API につないだ後に閲覧の権限の外の職員を出すかは未決

**カタログ**: [StaffFilterSidebar の AllStaff](https://buddy-docs.emon-apps.workers.dev/storybook/?path=/story/画面-schedule-stafffiltersidebar--all-staff)

### インタラクション

#### 1. 外す、付ける

1. 外すときは、チームの外に選ばれた職員がいることを前提にする。
2. チームの職員をまとめて外す、付ける。名前の検索の間も、検索で隠れた職員を含める。URL の変わり方は職員のチェックボックスと同じ。

**活性条件**: 常に活性。ただし、最後の 1 人を外す操作は受け付けない

**表示条件**: 職員の取得が成功し、職員がチームに属するとき。休職と退職の職員は出さない。閲覧の権限の外の職員を出すかは未決

2. URL の `staff` を、選んだ職員の id の並びにする。全員を選ぶと `staff` を消す。

## 全体動作

### 初期処理

- 予定はブラウザだけで描き、サーバーは予定を描かない。
- 開いた直後のフォーカスは `body` にある。フォーカスを特定の要素へ移す処理は無い。
- ミニカレンダーの日の表は Tab で 1 度だけ止まり、表の中は矢印のキーで動く（[ミニカレンダーの日](#ミニカレンダーの日)）。
- 予定、職員、チーム、利用者の一覧を取る。取得が終わる前は、ツールバーの全ての操作、ミニカレンダー、「キャンセルした予定を出す」、名前の検索、絞り込んでいるときの「全員を表示」を受け付ける。カレンダーを出していないので、予定、空いた日、空いた時間、時間の枠は押せない。取得が終わった後は、全ての操作を受け付ける。
- 取得の失敗は、3 回まで取り直してから出す。
- 職員の一覧は、休職と退職の職員も含めて取る。休職と退職の職員は、職員の絞り込み、職員の列、予定から除き、残りの職員の並びは変えない。
- BFF を通すときに API が 401 を返したら、今の画面に戻るログインの画面へ移る。フェイクの API は 401 を返さない。

### 履歴と、予定のモーダル

- URL を変える操作は、どれも履歴に積む。ブラウザの戻るで前の表示に戻る。
- 予定の作成、詳細、編集は、この画面の上にモーダルで重ねて出す。モーダルの URL は `/schedule` の子で、カレンダーの search params を引き継ぐ。

### 幅による配置

- 「キャンセルした予定を出す」、職員の絞り込みのチェックボックス、「自分だけ」、「全員を表示」、名前の検索、前の月、次の月、空いた時間の枠、時間の枠の押せる領域は 44px 以上にする。ミニカレンダーの日は、押せる領域の高さを 44px にする。予定の押せる領域は、予定の長さで決まる（[予定](#予定)）。

幅 768px 未満では、配置を次のように変える。ページは幅 320px でも横に送らない。

- 左の欄を、左端から開く「日付と絞り込み」のドロワーにする。ドロワーは閉じた状態で始まり、ヘッダーのメニューのボタンで開く。
- ツールバーを折り返し、表示の単位を幅いっぱいにする。
- カレンダーの左右の余白を 8px にする。
- 日の表示の職員の列は、職員ごとの日の表の中で横に送る。

### URL の search params からの復元

読めない値はデフォルト値に置き換え、デフォルト値は URL から消す。

| search param | 値 | 省いたときと読めないとき |
| --- | --- | --- |
| `view` | `month`、`week`、`day` | `month` |
| `date` | `YYYY-MM-DD` | 今日 |
| `staff` | 職員の id の配列。JSON の配列を符号化した形で、`["staff-1","staff-2"]` は `staff=%5B%22staff-1%22%2C%22staff-2%22%5D` になる。休職と退職の職員の id は、職員の一覧を取った後に除く | 空の配列（全ての職員）。休職と退職の職員の id だけのときも同じ |
| `cancelled` | `true`、`false` | `false`（キャンセルした予定を出さない） |

## 未決

PRD と実装が食い違うところ。

- PRD は、初めて開いたときに見る権限がある職員の全部を出すとしている。実装は、フェイクの API の事業所の全ての職員を出す。職員の絞り込みに閲覧の権限の外の職員を出すかが決まっていない。
- PRD の時間外の勤務の印を、カレンダーに出していない。

決まっていないところ。

- 予定が 0 件のときに、案内の文を出すか。
- 403 と 404 も、取得の失敗として 3 回取り直してから出している。4xx を取り直さないかが決まっていない。
- 403 を、ほかの取得の失敗と同じ文で出すか、権限が無いことを示す文に分けるか。
- 週と日の表示は 6 時から 22 時だけを出す。夜勤のようにその外の時刻にかかる予定を、どう見せるか。
- 予定の一覧の期間と職員の絞り込みを、API で絞るか画面で絞るか。OpenAPI の予定の一覧は日付の範囲だけを受ける。
- 編集の権限が自分の予定だけの職員に、「予定を作成」と、ほかの職員の列の時間の枠を出すか。
