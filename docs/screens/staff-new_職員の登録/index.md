# staff-new 職員の登録

職員の管理の権限を持つ職員が、新しい職員をメールアドレス、所属、役職で登録する画面。  
職員の一覧の上にモーダルで重ねて出す。  
登録した職員は、そのメールアドレスで最初にログインしたときから buddy を使える。

| 項目 | 値 |
| --- | --- |
| URL | `/staff/new`。`/staff` の子 |
| 使う人 | 職員の管理の権限を持つ職員。デフォルトはマネージャー |
| 実装 | `apps/web/src/routes/staff.new.tsx`、`apps/web/src/features/staff/components/StaffCreateDialogContainer.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

画面を描くコンポーネントのうち、実装の行のほかのものは次のとおり。

- `apps/web/src/features/staff/components/StaffCreateDialog.tsx`
- `packages/ui/src/patterns/InputDialog.tsx`

## 構成

[職員の一覧](../staff-list_職員の一覧/index.md) の上に覆いを重ね、その上にダイアログを出す。  
ダイアログは [画面仕様書の規約のダイアログ](../rules.md#ダイアログ) の入力のダイアログの形にする。  
ヘッダーの左にタイトルとヘルプを、右上に閉じるボタンを、本文に入力の欄を、フッターの右にキャンセルと登録のボタンを置く。  
ヘルプの説明の印は、ヘルプを開くと出る。  
部署、チーム、役職は、幅 768px 以上では横に並べ、幅 768px 未満では縦に並べる。

## 覆い

**概要**: 職員の一覧の上に重ね、ダイアログの外を押せないようにする覆い。

**値のソース**: 半透明の面

**操作**: 押すと、何も登録せずにダイアログを閉じ、職員の一覧に戻る。

1. 登録を送っている間は、押しても閉じない。

## ダイアログのタイトル

**概要**: 何のダイアログかを示すラベル。

**値のソース**: 「職員を登録」

## ヘルプ

**概要**: 登録した職員がいつから使えるかを、見たいときに示すボタン。  
ダイアログのタイトルの右に出す。  
形は [画面仕様書の規約の補足とヘルプ](../rules.md#補足とヘルプ) の ? のヘルプにする。

**値のソース**: 「?」のボタン。  
読み上げる名前は「ヘルプ」。  
押すと、ダイアログのタイトルの下に次の説明を出す。

| 説明 |
| --- |
| 「登録した職員は、このメールアドレスで最初にログインしたときから使えます。」 |

**操作**: 押すと、ダイアログのタイトルの下に説明を開く。

1. もう一度押すか、説明の外を押すか、Escape キーを押すと閉じる。

## 閉じる

**概要**: 登録せずにダイアログを閉じるボタン。  
ダイアログの右上に出す。

**値のソース**: × のアイコン。  
読み上げる名前は「閉じる」。

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない

**操作**: 押すか Escape キーを押すと、何も登録せずにダイアログを閉じ、職員の一覧に戻る。

## 名前

**概要**: 職員の名前を入れるテキストボックス。  
予定のカレンダーの職員の列と、照合の主訪問者に出る名前である。

**値のソース**: 見出し「名前」。  
最初は空。  
128 文字まで入れられる。

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない

## メールアドレス

**概要**: 職員がログインに使うメールアドレスを入れるテキストボックス。

**値のソース**: 見出し「メールアドレス」と、欄の下の次の文言。

| 文言 |
| --- |
| 「ログインに使うメールアドレス。登録した後は変えられません。」 |

最初は空。  
大文字と小文字は区別せず、小文字にそろえて保存する。

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない

## 電話番号

**概要**: 職員の電話番号を入れるテキストボックス。  
省いてよい。

**値のソース**: 見出し「電話番号（任意）」。  
最初は空。  
数字で 11 桁まで。  
超えたときは、登録を押すと [入力の誤りの文](#入力の誤りの文) を出す。

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない

## 部署

**概要**: 職員の部署を選ぶセレクト。

**値のソース**: 見出し「部署」と、事業所の部署の名前の選択肢。  
最初は名前の順の最初の部署を選ぶ。  
部署は、この画面では作らず、[部署とチーム](../organization-list_部署とチーム/index.md) で作る。

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない
- 事業所の部署を読み終えている
  - 読めなかったときも押せない。

## チーム

**概要**: 職員の所属のチームを選ぶセレクト。  
役職に決まっている権限のうち、チームを対象にする権限は、このチームを指す。

**値のソース**: 見出し「チーム」と、事業所のチームの名前の選択肢。  
最初は名前の順の最初のチームを選ぶ。  
チームは、この画面では作らず、[部署とチーム](../organization-list_部署とチーム/index.md) で作る。

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない
- 事業所のチームを読み終えている
  - 読めなかったときも押せない。

## 役職

**概要**: 職員の役職を選ぶセレクト。

**値のソース**: 見出し「役職」と、事業所の役職の名前の選択肢と、欄の下の次の文言。  
最初は名前の順の最初の役職を選ぶ。

| 文言 |
| --- |
| 「役職で権限が決まります。」 |

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない
- 事業所の役職を読み終えている
  - 読めなかったときも押せない。

## 訪問

**概要**: 職員が訪問するかを選ぶラジオボタン。  
訪問しない職員は、予定のカレンダーの職員の列と絞り込み、予定の職員と主訪問者と同行者の候補、利用者の担当の候補に出ない。  
事務の職員のような、訪問しない職員を登録するときに「訪問しない」を選ぶ。  
役職からは決めず、役職を選び直しても選択は変えない。  
ADR-0006: [訪問するかを職員に持ち、訪問しない職員を予定と担当から外す](../../adr/0006-non-visiting-staff.md)

**値のソース**: 見出し「訪問」と、選択肢「訪問する」「訪問しない」と、欄の下の次の文言。  
最初は「訪問する」を選ぶ。

| 文言 |
| --- |
| 「訪問しない職員は、予定のカレンダーの列と、予定と担当の候補に出ません。」 |

**操作**: 選択肢を押すと、押した選択肢を選ぶ。

## 入力の誤りの文

**概要**: 登録できない入力を、欄ごとに示すメッセージ。  
読み上げでは警告として扱う。

**値のソース**: 誤った欄の下に、欄ごとに次の文言を出す。  
誤った欄を直すと、その欄の文を消す。

| 欄 | 条件 | 文言 |
| --- | --- | --- |
| 名前 | 空 | 「名前を入れてください」 |
| メールアドレス | 空か、メールアドレスの形でない | 「メールアドレスの形で入れてください」 |
| 電話番号 | 数字と先頭の + 以外を含むか、数字が 11 桁を超える | 「電話番号は数字で 11 桁まで入れてください」 |

## 登録の失敗の文

**概要**: 登録できなかった理由を示すメッセージ。  
読み上げでは警告として扱う。

**値のソース**: ダイアログの下端の、ボタンの左に、理由ごとに次の文言を出す。

| 理由 | 文言 |
| --- | --- |
| 同じメールアドレスの職員が、この事業所かほかの事業所にいる | 「このメールアドレスの職員は、すでに登録されています。」 |
| 部署、チーム、役職が無くなった | 「部署、チーム、役職のどれかが見つかりません。開き直してから、選び直してください。」 |
| 職員の管理の権限を外された | 「この操作をする権限がありません。」 |
| つながらないか、ほかの理由で登録できなかった | 「登録できませんでした。時間をおいて、もう一度登録してください。」 |

## キャンセル

**概要**: 登録せずにダイアログを閉じるボタン。

**値のソース**: 「キャンセル」

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない

**操作**: 押すと、何も登録せずにダイアログを閉じ、職員の一覧に戻る。

## 登録

**概要**: 入れた値で職員を登録するボタン。

**値のソース**: 次の文言。

| 状態 | 文言 |
| --- | --- |
| 送る前 | 「登録」 |
| 送っている間 | 「登録しています」 |

**活性**: 次の全てに当てはまるとき。

- 職員が、登録を送っている途中でない
- 事業所の部署を読み終えている
  - 選択肢を読み終えるまでは、選ぶ欄に入れられないためである。読めなかったときも押せない。
- 事業所のチームを読み終えている
- 事業所の役職を読み終えている

**操作**: 押すと、入れた値で職員を登録する。

1. 入力が誤っていれば、送らずに「入力の誤り」の状態にする。
2. 誤りが無ければ、職員を登録する。
3. 登録できたら、ダイアログを閉じ、登録した職員の [職員の詳細](../staff-detail_職員の詳細/index.md) へ移る。
   - 役職に決まっている権限が付いたことを、詳細の権限のタブで確認できる。
4. 登録できなかったら、ダイアログを閉じずに「登録の失敗」の状態にする。
   - 入れた値は残す。

## 全体動作

### 初期処理

- 職員の管理の権限を持たない職員が開くと、ダイアログを出さず、[職員の一覧](../staff-list_職員の一覧/index.md) の「権限が無い」の状態にする。
- 職員の管理の権限を持つ職員が開くと、職員の一覧の上にダイアログを出し、部署、チーム、役職の選択肢を読む。
  - 選択肢を読めなかったときは、選択の欄を押せないままにし、登録の失敗の文の位置に「部署、チーム、役職を読み込めませんでした。閉じてから、開き直してください。」を出す。
  - 読む選択肢は、[職員の管理の Design Doc の職員の管理の画面の読み込みと保存](https://github.com/Fukuemon/buddy/blob/develop/services/schedule/internal/features/staff/DesignDoc.md#職員の管理の画面の読み込みと保存) にある。
- フォーカスは名前の欄に置く。
- URL の search params は読まない。

## 未決

### 決まっていないこと

- 職員の性別を持つか。
  - 今の動き: 職員の性別は持たず、この画面に性別の欄は無い。
  - 決める人: 開発者。PRD の Open Questions にある。
  - 期限: 担当の候補を性別で絞る機能を作るとき
- 役職に決まっている権限は、事業所の使い方に合うか。
  - 今の動き: PRD の役職ごとの権限の表を仮決定として使う。この画面は、確認の結果によらず、役職を選ぶだけにする。
  - 決める人: 開発者が、事業所の責任者に確認して決める。PRD の Open Questions にある。
  - 期限: 事業所で使い始めるまで
