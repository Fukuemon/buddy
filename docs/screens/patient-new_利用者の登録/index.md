# patient-new 利用者の登録

職員の管理の権限を持つ職員が、新しい利用者を、名前、サービス、希望、担当の職員で登録する画面。  
利用者の一覧の上にモーダルで重ねて出す。  
登録した利用者は、登録したときから予定の利用者の候補に出る。

| 項目 | 値 |
| --- | --- |
| URL | `/patients/new`。`/patients` の子 |
| 使う人 | 職員の管理の権限を持つ職員。デフォルトはマネージャー |
| 実装 | `apps/web/src/routes/patients.new.tsx`、`apps/web/src/features/patient/components/PatientCreateDialogContainer.tsx` |

画面の項目と、web の型、OpenAPI の項目の対応は [API との対応](api.md) にある。

画面を描くコンポーネントのうち、実装の行のほかのものは次のとおり。

- `apps/web/src/features/patient/components/PatientCreateDialog.tsx`
- `apps/web/src/features/patient/components/PatientFormFields.tsx`
- `packages/ui/src/base/FormField/FormField.tsx`
- `packages/ui/src/patterns/InputDialog.tsx`

## 構成

[利用者の一覧](../patient-list_利用者の一覧/index.md) の上に覆いを重ね、その上に入力のダイアログを出す。  
ダイアログの形は [画面仕様書の規約のダイアログ](../rules.md#ダイアログ) にある。  
ダイアログの上端にタイトルと閉じるボタンを、本文に入力の欄を、下端にキャンセルと登録のボタンを置く。  
希望の時間帯と希望する担当の性別は、ラジオボタンを横に並べる。

## 覆い

**概要**: 利用者の一覧の上に重ね、ダイアログの外を押せないようにする。

**値のソース**: 半透明の面

**活性条件**: 常に活性

**表示条件**: ダイアログを開いている間

### インタラクション

#### 1. 押す

1. 何も登録せずにダイアログを閉じ、利用者の一覧に戻る。

## ダイアログのタイトル

**概要**: 何のダイアログかを示す。

**値のソース**: 「利用者を登録」

**活性条件**: 常に活性

**表示条件**: 常に表示

## 閉じる

**概要**: 登録せずにダイアログを閉じる。

**値のソース**: × のアイコン。  
読み上げる名前は「閉じる」。

**活性条件**: 常に活性

**表示条件**: 常に、タイトルの右に出す。

### インタラクション

#### 1. 押すか、Escape キーを押す

1. 何も登録せずにダイアログを閉じ、利用者の一覧に戻る。

## 名前

**概要**: 利用者の名前を入れる。  
予定の訪問の情報と、Google カレンダーに書き出す予定のタイトルに出る名前である。

**値のソース**: 見出し「名前」。  
最初は空。  
255 文字まで入れられる。

**活性条件**: 常に活性

**表示条件**: 常に表示

## サービス

**概要**: 利用者が受けているサービスを選ぶ。

**値のソース**: 見出し「サービス」と、「訪看I2（20〜29 分）」の形の、サービスコードと時間の範囲の選択肢。  
選択肢はサービスコードの一覧の順に並べる。  
最初は何も選ばず、「選んでください」を出す。

**活性条件**: サービスコードの選択肢を読み終えたとき

**表示条件**: 常に表示

## 希望の時間帯

**概要**: 利用者が希望する訪問の時間帯を選ぶ。

**値のソース**: 見出し「希望の時間帯」と、「午前」「午後」のラジオボタン。  
最初は何も選ばない。

**活性条件**: 常に活性

**表示条件**: 常に表示

## 希望する担当の性別

**概要**: 利用者が希望する担当の職員の性別を選ぶ。

**値のソース**: 見出し「希望する担当の性別」と、「男性」「女性」のラジオボタン。  
最初は何も選ばない。

**活性条件**: 常に活性

**表示条件**: 常に表示

## 担当の職員

**概要**: 利用者を主に担当する職員を選ぶ。  
担当の職員を退職にするには、先にこの利用者の担当を変えるか、利用を終了する必要がある。

**値のソース**: 見出し「担当の職員」と、事業所の有効な職員の名前の選択肢。  
休職と退職の職員は選択肢に出さない。  
訪問しない職員も出さない。  
ADR-0018: [照合を照合の権限で許し、事務の役職を足し、訪問しない職員を予定と担当から外す](../../adr/0018-receipt-check-policy-and-non-visiting-staff.md)  
選択肢は職員の名前の順に並べる。  
最初は何も選ばず、「選んでください」を出す。  
欄の下に「休職と退職の職員と、訪問しない職員は選べません。」を出す。  
入力の時点で守る制約なので、常に出す。

**活性条件**: 職員の選択肢を読み終えたとき

**表示条件**: 常に表示

## 入力の誤りの文

**概要**: 登録できない入力を、欄ごとに示す。  
読み上げでは警告として扱う。

**値のソース**: 欄ごとに次の文言。

| 欄 | 条件 | 文言 |
| --- | --- | --- |
| 名前 | 空 | 「名前を入れてください」 |
| サービス | 選んでいない | 「サービスを選んでください」 |
| 希望の時間帯 | 選んでいない | 「希望の時間帯を選んでください」 |
| 希望する担当の性別 | 選んでいない | 「希望する担当の性別を選んでください」 |
| 担当の職員 | 選んでいない | 「担当の職員を選んでください」 |

**活性条件**: 常に活性

**表示条件**: 登録を押し、入力が誤っていたとき。  
誤った欄を直すと、その欄の文を消す。

## 登録の失敗の文

**概要**: 登録できなかった理由を示す。  
読み上げでは警告として扱う。

**値のソース**: 理由ごとに次の文言。

| 理由 | 文言 |
| --- | --- |
| 選んだ担当の職員が、ダイアログを開いた後に休職か退職になった | 「選んだ担当の職員は、休職か退職になりました。別の職員を選んでください。」 |
| サービスコードか担当の職員が見つからない | 「サービスか担当の職員が見つかりません。開き直してから、選び直してください。」 |
| 職員の管理の権限を外された | 「この操作をする権限がありません。」 |
| ほかの理由で登録できなかった | 「登録できませんでした。時間をおいて、もう一度登録してください。」 |

**活性条件**: 常に活性

**表示条件**: 登録を押し、登録できなかったとき。  
ダイアログの下端の、ボタンの左に出す。

## キャンセル

**概要**: 登録せずにダイアログを閉じる。

**値のソース**: 「キャンセル」

**活性条件**: 常に活性

**表示条件**: 常に表示

### インタラクション

#### 1. 押す

1. 何も登録せずにダイアログを閉じ、利用者の一覧に戻る。

## 登録

**概要**: 入れた値で利用者を登録する。

**値のソース**: 次の文言。

| 状態 | 文言 |
| --- | --- |
| 送る前 | 「登録」 |
| 送っている間 | 「登録しています」 |

**活性条件**: 送っていない間

**表示条件**: 常に表示

### インタラクション

#### 1. 押す

1. 入力が誤っていれば、送らずに「入力の誤り」の状態にする。
2. 誤りが無ければ、利用者を登録する。
3. 登録できたら、ダイアログを閉じ、登録した利用者の [利用者の詳細](../patient-detail_利用者の詳細/index.md) へ移る。
4. 登録できなかったら、ダイアログを閉じずに「登録の失敗」の状態にする。
   - 入れた値は残す。

## 全体動作

### 初期処理

- 職員の管理の権限を持たない職員には、ダイアログを出さず、[利用者の一覧](../patient-list_利用者の一覧/index.md) の「権限が無い」の状態を出す。
- 権限を持つ職員には、利用者の一覧の上にダイアログを出す。
  - サービスと担当の職員の欄は、選択肢を読み終えるまで押せない。
  - 選択肢を読めなかったときは、選択の欄を押せないままにし、登録の失敗の文の位置に「サービスと職員を読み込めませんでした。閉じてから、開き直してください。」を出す。
- フォーカスは名前の欄に置く。
- URL の search params は読まない。

### 権限の確認

職員の管理の権限を持たない職員には、ダイアログを出さない。  
画面を開いた後に職員の管理の権限を外された職員が登録を押すと、[登録の失敗の文](#登録の失敗の文) に「この操作をする権限がありません。」を出す。
