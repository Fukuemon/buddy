検証の issue は [#946](https://github.com/Fukuemon/buddy/issues/946) である。

- [検証の設計](test-design.md)
- [検証のシナリオ](scenarios.md)

## 撮るシナリオ

spec は `packages/e2e/tests/evidence/schedule/schedule-deletion-acceptance.e2e.ts` である。  
検証環境ができるまで、pull request のエビデンスと同じ撮影の config で、ローカル環境の compose で撮る。  
入れる先は `issue-946` である。test の名前は、`name` と次の文を空白でつないだものである。

| シナリオ | `name` | test の名前の `name` の後の文 |
| --- | --- | --- |
| 単発の予定の削除 | `s1-single` | 明日の単発の予定を詳細から削除した場合、確認の後に日の表示から消え、キャンセルした予定を出しても出ないこと |
| 繰り返しの予定の回の削除 | `s2-occurrence` | 毎週の繰り返しの予定の 2 回目の回を詳細から削除した場合、その回だけが消え、キャンセルした予定を出しても出ず、1 回目と 3 回目は残ること |
| 削除できない予定 | `s3-hidden` | 自分の予定だけを編集できる職員が、昨日の予定、キャンセルした予定、ほかの職員の予定、明日の自分の予定の詳細を順に開いた場合、明日の自分の予定にだけ「予定を削除」が出ること |
| Google カレンダーで管理する事業所 | `s4-google-primary` | Google カレンダーで管理する事業所の職員が明日の予定の詳細を開いた場合、「予定を削除」が出ず、「予定をキャンセル」で取り消すと Google カレンダーからも消えること |
| Google カレンダーに書き出した予定の削除 | `s5-export` | Google カレンダーを結び付けた職員の、書き出した予定を詳細から削除した場合、予定のカレンダーと Google カレンダーから消えること |

- 字幕は、シナリオの文の「前提」「もし」「ならば」を先頭に付け、「明日」のような言葉を、撮った日付と予定のタイトルに置き換えて出す。

## spec を置かないシナリオ

なし。

## 撮影のための操作

- 予定は、録画の外（`prepareOutsideRecording`）で、青木 陽菜のトークンで予定の API から作る。キャンセルした予定も、録画の前に予定の API でキャンセルする。
- 削除できない予定のシナリオは、setup が保存した林 さくらのログインの状態で撮る。予定は、録画の外で青木 陽菜のトークンで作る。
- Google カレンダーで管理する事業所のシナリオの予定は、録画の前に calendarpit の管理の API で作り、同期が予定のカレンダーに出すまで日の表示を開き直して待つ。取り消せなかったときは、撮った後に calendarpit から消す。
- 書き出した予定の削除のシナリオは、録画の前にカレンダーの連携の画面で林 さくらに calendarpit のカレンダーを結び付け、書き出しが calendarpit に予定を作るまで待つ。撮った後に結び付けを外す。
