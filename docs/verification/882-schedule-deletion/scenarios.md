# 誤って入れた予定の削除の検証のシナリオ

[#882](https://github.com/Fukuemon/buddy/issues/882) の受け入れの条件を確認するシナリオ。  
観点の選び方は [test-design.md](test-design.md) に、spec との対応は [README.md](README.md) にある。

## 共通の前提

- 予定を buddy で管理する事業所（`buddy_primary`）のアクターは、シードのサンプル訪問看護ステーションの職員である。
  - マネージャーの青木 陽菜は、事業所のどの職員の予定も編集できる。
  - メンバーの林 さくらは、自分の予定を編集でき、チームリーダーの森 健太の予定を見られる。
- Google カレンダーで管理する事業所（`google_primary`）のアクターは、シードのサンプル第三訪問看護ステーションのマネージャーの岡田 葵である。
- Google カレンダーは、ローカル環境の calendarpit である。
- 予定は、録画の前に予定の API か calendarpit の管理の API で作る。
- 日付は撮る日から決める。「今日」と「明日」は Asia/Tokyo の日付である。

## 単発の予定の削除

- `@scenario-id`: `882-single`

```text
前提 青木 陽菜 の明日の 10:00〜11:00 に予定があり、11:00〜12:00 の予定をキャンセルしてある
もし 10:00 の予定の詳細で「予定を削除」を押す
ならば 削除の確認のダイアログに「この予定を削除しますか」、予定の日時、誤って入れた予定を消すことの説明が出る
もし 「予定を削除する」を押す
ならば 詳細が閉じ、明日の日の表示から予定が消える
もし 「キャンセルした予定を出す」を入れる
ならば キャンセルした 11:00 の予定は取り消し線で出て、削除した 10:00 の予定は出ない
```

## 繰り返しの予定の回の削除

- `@scenario-id`: `882-occurrence`

```text
前提 林 さくら に、明日以降で最初の月曜から毎週月曜 10:00〜11:00 の繰り返しの予定がある
もし 青木 陽菜 が 2 回目の月曜の回の詳細で「予定を削除」を押す
ならば 削除の確認のダイアログの説明に、この日の回だけを消し、ほかの回は残ることが出る
もし 「予定を削除する」を押す
ならば 2 回目の月曜の日の表示から回が消え、「キャンセルした予定を出す」を入れても出ない
かつ 1 回目と 3 回目の月曜の日の表示には回が出る
```

## 削除できない予定

- `@scenario-id`: `882-hidden`

```text
前提 林 さくら の昨日の予定、林 さくら の明日のキャンセルした予定、森 健太 の明日の予定、林 さくら の明日の予定がある
もし 林 さくら が昨日の自分の予定の詳細を開く
ならば 「予定をキャンセル」と「編集」は出て、「予定を削除」は出ない
もし 明日の自分のキャンセルした予定の詳細を開く
ならば 「予定を削除」は出ない
もし 明日の 森 健太 の予定の詳細を開く
ならば 「閉じる」だけが出て、「予定を削除」は出ない
もし 明日の自分の予定の詳細を開く
ならば 「予定を削除」が出る
```

## Google カレンダーで管理する事業所

- `@scenario-id`: `882-google-primary`

```text
前提 岡田 葵 の Google カレンダーの明日の 13:00〜14:00 に予定があり、予定のカレンダーに出ている
もし 岡田 葵 が予定の詳細を開く
ならば 「予定をキャンセル」と「編集」は出て、「予定を削除」は出ない
もし 理由を入れて「予定をキャンセル」で取り消す
ならば 予定のカレンダーから予定が消え、Google カレンダーからも予定が消える
```

## Google カレンダーに書き出した予定の削除

- `@scenario-id`: `882-export`

```text
前提 林 さくら に Google カレンダーを結び付けてあり、林 さくら の明日の 16:00〜17:00 の予定が Google カレンダーに書き出されている
もし 青木 陽菜 が予定の詳細の「予定を削除」から予定を削除する
ならば 予定のカレンダーから予定が消える
かつ 林 さくら の Google カレンダーからも予定が消える
```
