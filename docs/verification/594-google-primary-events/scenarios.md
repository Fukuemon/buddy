# Google カレンダーを正本にする事業所の、取り込めない予定の扱いの検証のシナリオ

[#594](https://github.com/Fukuemon/buddy/issues/594) の受け入れの条件の 5 つ目を確認するシナリオ。  
観点の選び方は [test-design.md](test-design.md) に、spec との対応は [README.md](README.md) にある。

## 共通の前提

- アクターは、シードの `google_primary` の事業所（サンプル第三訪問看護ステーション）のマネージャーの岡田 葵である。
- 岡田の Google カレンダーは、ローカル環境の calendarpit の `aoi.okada@example.com` である。
- 予定は calendarpit の管理の API で作り、同期が Projection に写した後に、予定のカレンダーの週の表示で見る。
- 日付は撮る日から決める。シナリオの「1 つ目の週」は、撮る日の週から数えた週である。

## 繰り返しの予定と例外の回

- `@scenario-id`: `594-recurring`

```text
前提 岡田 葵 の Google カレンダーに、毎週火水木の 13:00〜14:00 の予定（水曜の回を 15:00〜16:00 に変え、木曜の回を取り消した）と、月曜 10:00 から 1 日おきに 3 回の予定がある
もし その週を週の表示で開く
ならば 格子に毎週の予定の火曜 13:00 の回と、時刻を変えた水曜 15:00 の回が出て、取り消した木曜の回は出ない
かつ 1 日おきの予定は月曜の最初の回だけが格子に出て、通知の欄の確認が必要な予定に「繰り返しの規則を buddy で表せないため、最初の回だけを表示しています」と出る
```

## 終日の予定

- `@scenario-id`: `594-all-day`

```text
前提 岡田 葵 の Google カレンダーに、月曜の 1 日の終日の予定、水曜から金曜の終日の予定、毎週火曜と木曜の終日の予定（1 つ目の週の木曜の回を除外した）がある
もし 1 つ目の週を週の表示で開く
ならば 「終日」の行の月曜に 1 日の予定、水曜から金曜に何日かの予定、火曜に毎週の予定が出て、除外した木曜には毎週の予定が出ない
もし 次の週を開く
ならば 「終日」の行の火曜と木曜に毎週の予定が出る
```

## 訪問の情報に変換できない予定

- `@scenario-id`: `594-visit-unresolved`

```text
前提 岡田 葵 の Google カレンダーの月曜に、「【訪看I2】<登録した利用者>」、「【訪看I2】<登録していない利用者>」、「【<サービスコードに無いサービス内容>】<登録した利用者>」、「【訪看I2】<同じ名前の利用者が 2 人いる名前>」、タイトルが空白だけの予定がある
もし その週を週の表示で開く
ならば 月曜の格子に 5 件の予定が出る
かつ 通知の欄に「確認が必要な予定が 4 件あります」と出て、「タイトルの利用者が見つかりません」「タイトルのサービス内容がサービスコードにありません」「タイトルの利用者が 2 人以上います」「タイトルを読めません」の 4 件が並ぶ。登録した利用者の予定は確認が必要な予定に出ない
```

## カレンダーに出せない予定

- `@scenario-id`: `594-unlisted`

```text
前提 岡田 葵 の Google カレンダーに、月曜の終了の日時を読めない予定（中継の gcalhold が壊して返す）、水曜 18:00 から翌日 09:00 の予定、火曜 13:00〜14:00 の予定がある
もし その週を週の表示で開く
ならば 通知の欄に「カレンダーに出せない予定が 2 件あります」「岡田 葵: 2 件」と、Google カレンダーで確認する案内が出る
かつ 格子に火曜の予定が出て、終了を読めない予定と 2 日にわたる予定は出ない
```

## 写せない繰り返しの終日の予定

- `@scenario-id`: `594-all-day-unsupported`

```text
前提 岡田 葵 の Google カレンダーに、月曜から 1 日おきに 5 回の終日の予定がある（回は月曜、水曜、金曜、次の週の日曜と火曜）
もし 1 つ目の週を週の表示で開く
ならば 「終日」の行の回の日に予定が出るか、通知の欄の確認が必要な予定に「繰り返しの規則を buddy で表せないため、最初の回だけを表示しています」と出る
もし 次の週を開く
ならば 「終日」の行の日曜と火曜に予定が出るか、通知の欄の確認が必要な予定に「繰り返しの規則を buddy で表せないため、最初の回だけを表示しています」と出る
```

- 期待結果は、ADR-0029 の「展開できない繰り返しの規則の予定は、確認が必要な予定として 1 件で返し、一覧から落とさない」から書いた。どちらの出し方にするかは決まっていない。
