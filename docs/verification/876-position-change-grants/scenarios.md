# 役職を変えても職員ごとに足した権限が残ることの検証のシナリオ

[#876](https://github.com/Fukuemon/buddy/issues/876) の受け入れの条件を確認するシナリオ。  
観点の選び方は [test-design.md](test-design.md) に、spec との対応は [README.md](README.md) にある。

## 共通の前提

- アクターは、シードのサンプル訪問看護ステーションの職員である。
  - マネージャーの青木 陽菜（チーム A）は、職員の管理の権限を役職のデフォルトで持つ、事業所で唯一の有効な管理者である。
  - チーム A に林 さくら、チーム B にリーダーの森 健太とメンバーの佐藤 美咲がいる。
- 撮る職員は、撮影の前に予定の API で登録するチーム A のメンバーである。名前はシナリオごとに分ける（受入 一子、受入 二郎、受入 三奈、受入 四郎）。登録したメールで、ブローカーからログインできる。
- 予定は、撮影の前に予定の API で作る。「明日」は、撮る日の翌日（Asia/Tokyo）である。
- 役職のデフォルトの権限は、メンバーが自分の予定の編集だけ、リーダーが自分の予定の編集と、所属のチームを対象にするチームの予定の閲覧と編集である。

## 個別に足した権限は役職を変えても残る

- `@scenario-id`: `876-keep-individual`

```text
前提 チーム A のメンバーの 受入 一子 の職員の詳細を、青木 陽菜 が開いている
もし 権限のタブで「指定した職員の予定の閲覧」を対象「森 健太」で足す
ならば 「個別に足した権限」に「指定した職員の予定の閲覧」と対象「森 健太」が出る
もし 「役職を変える」で「リーダー」を選ぶ
ならば 注意に「役職を変えると、受入 一子 の役職で付く権限は、新しい役職で付く権限に置き換わります。個別に足した権限（指定した職員の予定の閲覧）は残ります。」が出る
もし 「役職を変える」を押す
ならば 役職が「リーダー」になり、「役職「リーダー」で付く権限」に 3 つの権限が出る
かつ 「個別に足した権限」に「指定した職員の予定の閲覧」と対象「森 健太」が残る
```

## 残った権限が予定の判定に使われ、外すと使われない

- `@scenario-id`: `876-kept-grant-authorizes`

```text
前提 「指定した職員の予定の閲覧」（森 健太）を個別に足したチーム A のメンバーの 受入 二郎 を、リーダーに変えてある
前提 明日に、林 さくら、森 健太、佐藤 美咲 の予定がある
もし 受入 二郎 でログインし、明日の日の表示を開く
ならば 林 さくら（リーダーのチームの予定の閲覧、チーム A）と 森 健太（個別に足した権限）の列が出て、佐藤 美咲 の列は出ない
もし (撮影のため) 青木 陽菜 が API で 受入 二郎 から「指定した職員の予定の閲覧」を外す
かつ 日の表示を読み込み直す
ならば 森 健太 の列が出なくなる
```

## 新しい役職のデフォルトにもある個別の権限は対象が残り、判定もその対象で行う

- `@scenario-id`: `876-overlap-target`

```text
前提 チーム A のメンバーの 受入 三奈 に「指定したチームの職員の予定の閲覧」を対象「B」で個別に足し、リーダーに変えてある
前提 明日に、林 さくら と 森 健太 の予定がある
前提 受入 三奈 でログインし、自分の情報を開いている
ならば 「チームの予定の閲覧」の対象は「B」だけで、「チームの予定の編集」の対象は「A」である
もし 明日の日の表示で 森 健太 の予定の詳細を開く
ならば 「閉じる」だけが出て、「編集」は出ない
もし 林 さくら の予定の詳細を開く
ならば 「編集」が出る
```

## 個別に足した職員の管理の権限だけを持つ最後の管理者は、その権限の無い役職に変えられる

- `@scenario-id`: `876-last-manager-individual`

```text
前提 チーム A のメンバーの 受入 四郎 に「職員の管理」を個別に足し、青木 陽菜 をリーダーに変えてあり、受入 四郎 が事業所で唯一の有効な管理者である
もし 受入 四郎 が自分の職員の詳細で「役職を変える」から「リーダー」を選んで保存する
ならば 役職が「リーダー」になる
かつ 権限のタブの「個別に足した権限」に「職員の管理」が残る
```

- 撮った後に、受入 四郎 のトークンで青木 陽菜を管理者に戻し、青木 陽菜のトークンで 受入 四郎 の「職員の管理」を外す。
