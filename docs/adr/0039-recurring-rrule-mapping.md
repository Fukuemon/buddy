# ADR-0039: Google カレンダーの RRULE のうち、buddy の繰り返しの規則と毎日の繰り返しを規則に写し、書き出す RRULE に週の始まりの日曜を書く

## Status

承認

## Context

google_primary の事業所では、Google カレンダーの繰り返しの予定を buddy の規則に写して出し、写せない予定を確認が必要な予定（`recurrence_unsupported`）にする。buddy_primary の事業所では、buddy の規則を RRULE に直して Google カレンダーに書き出す（[ADR-0029](0029-google-calendar-sync.md)）。

決定に関わる事実は次のとおり。

- buddy の毎週の規則は、複数の曜日と 1〜52 の間隔を持ち、隔週の週を日曜に始まる週で数える（[ADR-0038](0038-recurring-rule-scope.md)）。
- 照合の API は、buddy の回を読まず、Google カレンダーが展開した回を読む。buddy_primary の事業所でも、書き出した予定を読む。照合が buddy の回と同じ回を読むには、書き出した RRULE を Google が展開した回と、buddy が求めた回が一致する必要がある。
- RFC 5545 の `WKST` は週の始まりの曜日で、デフォルトは月曜である。毎週で間隔が 2 以上かつ曜日が複数のときだけ、`WKST` で回が変わる。
  - 出典: [RFC 5545 の 3.3.10](https://www.rfc-editor.org/rfc/rfc5545.txt)
- Google の画面が作る RRULE と、`WKST` を付けるか、付けるときの値は、公式の資料で確認できなかった。

## Decision

Google の RRULE のうち、buddy の規則と同じ範囲と、間隔 1 の毎日を、規則に写す。この範囲は、利用者が選んだ。

- 写すのは次の形である。どれも、終わりは `UNTIL` か `COUNT` か無しで、`COUNT` は最後の回の日付を終了日にする（ADR-0038）。
  - `FREQ=WEEKLY` で、`INTERVAL` が 1〜52 で、`BYDAY` が数字の無い 1 つ以上の曜日か無いもの
  - `FREQ=DAILY` で、`INTERVAL` が 1 で、`BY` の付く項目が無いもの。7 つの曜日の毎週にする。特別訪問看護指示書の期間の毎日の訪問を、buddy で変えられるようにするためである。
  - 今と同じ毎月の形（`BYMONTHDAY` が 1 つ、`BYDAY` が第 1〜5 週の曜日 1 つ、`BY` が無い）
- `INTERVAL` が 2 以上かつ曜日が複数の毎週は、`WKST` の週の区切りが、buddy の日曜始まりの週の区切りと同じ曜日の組を作るときだけ写す。
  - `WKST=SU` は写す。
  - `WKST` が無い（月曜）か `WKST=MO` のときは、日曜だけが前の週に入るので、`BYDAY` に日曜が無ければ写し、あれば写さない。
  - ほかの `WKST` は写さない。
  - 間隔が 1 か曜日が 1 つのときは、`WKST` で回が変わらないので、`WKST` によらず写す。
- 写せない形（最終の曜日、`BYSETPOS`、`RDATE`、間隔が 2 以上の毎日、毎年、毎月の間隔、Asia/Tokyo でない予定）は、今と同じく確認が必要な予定にする。
- 書き出す毎週の RRULE には、`INTERVAL` と、全ての曜日の `BYDAY` と、`WKST=SU` を書く。Google が展開する回を、buddy が求める回と一致させるためである。毎日から写した予定も、7 つの曜日の毎週として書き出す。

## Considered Options

| 選択肢 | 強み | 弱み |
| --- | --- | --- |
| **採用:** buddy の規則と同じ範囲と、間隔 1 の毎日を写し、書き出しに `WKST=SU` を書く | 毎日の訪問も buddy で変えられる。照合が読む回と buddy の回が一致する | 毎日の予定は、書き出すと 7 つの曜日の毎週になり、Google の元の形と変わる。月曜始まりの隔週で曜日が複数の予定は写せない |
| buddy の規則と同じ範囲だけを写す | 写す規則と書き出す規則が同じ形になる | Google で作った毎日の予定が、確認が必要な予定のまま残る |
| 最終の曜日と毎月の複数の曜日も写す | 写せる予定が増える | buddy の規則と画面の項目が増える。訪問で要る根拠が無い |
| 規則に週の始まりを持ち、`WKST` によらず写す | 隔週の Google の予定を全て写せる | 画面に職員が気にしない項目が増える |

## Consequences

### Positive

- 週に 2 回、隔週、毎日の Google の繰り返しの予定を、確認が必要な予定にせずに出せる。
- 書き出した繰り返しの予定の回を、照合が buddy の回と同じく読む。

### Negative

- 月曜始まりの隔週で、日曜を含む複数の曜日の Google の予定は、確認が必要な予定のまま残る。
- Google の Calendar API が `WKST=SU` の RRULE を RFC 5545 のとおりに展開するかは、公式の資料で確認できていない。予定の API のタスクで、日曜を含む隔週の予定を書き出し、Google カレンダーの回が buddy の回と同じ日に出ることを確認する。
- 既に書き出した繰り返しの予定の RRULE は、`WKST=SU` を持たない。間隔が 1 で曜日が 1 つなので、回は変わらない。
