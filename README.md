# buddy

訪問看護の事業所の職員が、予定の管理とレセプトの照合を、1 つの web アプリで行う。  
職員は、事業所の IdP（Google など）のアカウントでログインする。  
照合は、Google カレンダーの予定と電子カルテの実績の CSV を比べ、食い違いの一覧を返す。
